
> claude --dangerously-skip-permissions
 ▶︎ .claude/settings.json 설정 내 deny 항목도 무시된다.


> JSON 출력 + 최대 턴 수 제한
```
claude -p "보안 취약점 검토해줘" \ --output-format json \ --max-turns 5 \ --permission-mode bypassPermissions
```
