## Python Private LLM 개발 도구 완전 총정리

### 한눈에 보기

| 카테고리 | 추천 도구 | 필수 여부 | 비고 |
|----------|-----------|-----------|------|
| 가상환경 & 패키지 관리 | `uv` | 필수 | pip/venv 대체 |
| 린터 | `ruff` | 필수 | flake8 + isort 대체 |
| 포매터 | `ruff format` | 필수 | black 대체 |
| 데이터 검증 | `pydantic` | 필수 | 런타임 데이터 검증 |
| 타입 체크 | `pyright` | 팀이면 필수 | CI/CD 정적 분석 |
| 에디터 타입 지원 | `pylance` | 필수 | VSCode 전용, pyright 내장 |
| 단위 테스트 | `pytest` | 필수 | 표준 테스트 러너 |
| API Mock | `respx` + `pytest-mock` | 필수 | LLM API 모킹 |
| 통합 테스트 | `testcontainers` | 권장 | 실제 인프라 테스트 |
| 커버리지 | `pytest-cov` | 권장 | 커버리지 측정 |
| 환경변수 관리 | `pydantic-settings` | 필수 | .env 타입 안전 로딩 |
| Git 훅 자동화 | `pre-commit` | 강력 권장 | 커밋 전 자동 검사 |
| 보안 취약점 검사 | `bandit` | 권장 | 코드 보안 스캔 |
| 의존성 취약점 검사 | `pip-audit` | 권장 | 패키지 CVE 검사 |
| 로깅 | `loguru` | 강력 권장 | 표준 logging 대체 |
| LLM 테스트/평가 | `deepeval` | 권장 | LLM 응답 품질 평가 |

### 추가 도구 상세 설명

**`pydantic-settings` - 환경변수 관리**

Private LLM은 모델 경로, API 키, DB URL 등 설정값이 많아서 필수

```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    model_path: str
    openai_api_key: str
    vector_db_url: str
    temperature: float = 0.7

    class Config:
        env_file = ".env"

settings = Settings()  # .env 자동 로딩 + 타입 검증
```

---

**`pre-commit` - Git 훅 자동화**

커밋 전에 ruff, pyright 등을 자동 실행해서 나쁜 코드가 올라가는 것을 방지

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    hooks:
      - id: ruff
      - id: ruff-format
```

```bash
pre-commit install  # 한 번만 실행하면 이후 커밋마다 자동 실행
```

---

**`bandit` - 보안 취약점 검사**

LLM 시스템은 API 키, 사용자 입력 처리 등 보안이 중요

```bash
bandit -r src/
# 하드코딩된 패스워드, SQL 인젝션 위험 등 자동 탐지
```

---

**`loguru` - 로깅**

표준 logging보다 훨씬 간결하고 LLM 요청/응답 추적에 적합

```python
from loguru import logger

logger.info("LLM 요청: {prompt}", prompt=prompt)
logger.error("API 오류: {error}", error=e)

# 파일 로테이션, JSON 출력 등 간단히 설정 가능
logger.add("logs/llm.log", rotation="100 MB", format="json")
```

---

**`deepeval` - LLM 응답 품질 평가**

일반 테스트로는 LLM 응답의 품질을 측정하기 어려움

```python
from deepeval import assert_test
from deepeval.metrics import AnswerRelevancyMetric

def test_llm_relevancy():
    metric = AnswerRelevancyMetric(threshold=0.7)
    test_case = LLMTestCase(
        input="Python이란?",
        actual_output=llm.generate("Python이란?"),
    )
    assert_test(test_case, [metric])
```

### 설치 한 번에

```bash
# 프로젝트 초기화
uv init my-private-llm
cd my-private-llm

# 프로덕션 의존성
uv add pydantic pydantic-settings loguru

# 개발 도구
uv add --dev \
  pyright \
  ruff \
  bandit \
  pip-audit \
  pre-commit \
  pytest \
  pytest-asyncio \
  pytest-mock \
  pytest-cov \
  pytest-xdist \
  respx \
  testcontainers \
  deepeval
```

### pyproject.toml 통합 설정

```toml
[project]
name = "my-private-llm"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
  "pydantic",
  "pydantic-settings",
  "loguru",
]

# -----------------------------------------------
# Ruff - 린터 + 포매터
# -----------------------------------------------
[tool.ruff]
line-length = 88
target-version = "py311"

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B"]

# -----------------------------------------------
# Pyright - 타입 체커
# -----------------------------------------------
[tool.pyright]
strict = true
pythonVersion = "3.11"
include = ["src"]
exclude = ["tests"]

# -----------------------------------------------
# Pytest - 테스트
# -----------------------------------------------
[tool.pytest.ini_options]
asyncio_mode = "auto"
testpaths = ["tests"]
addopts = "--cov=src --cov-report=term-missing"

[tool.coverage.report]
fail_under = 80

# -----------------------------------------------
# Bandit - 보안 검사
# -----------------------------------------------
[tool.bandit]
targets = ["src"]
severity = "medium"
```

### 도구별 역할 흐름

```
개발 중 (코드 작성)
├── Pylance          → 실시간 타입 오류 표시 (VSCode)
├── ruff             → 저장 시 자동 린트 + 포맷
└── loguru           → 개발 중 디버그 로그

커밋 시 (pre-commit)
├── ruff check       → 린트 자동 검사
└── ruff format      → 포맷 자동 수정

실행 중 (런타임)
├── pydantic         → API 요청, JSON 데이터 검증
├── pydantic-settings → 환경변수 타입 안전 로딩
└── loguru           → 요청/응답 추적 로그

CI/CD (PR, 배포)
├── ruff check            → 린트 검사
├── ruff format --check   → 포맷 검사
├── pyright               → 정적 타입 검사
├── bandit                → 보안 취약점 검사
├── pip-audit             → 패키지 CVE 검사
├── pytest tests/unit/    → 단위 테스트
├── pytest tests/integration/ → 통합 테스트
└── deepeval              → LLM 응답 품질 평가
```

### CI/CD (GitHub Actions)

```yaml
jobs:
  ci:
    steps:
      - name: 린트 체크
        run: uv run ruff check src/

      - name: 포맷 체크
        run: uv run ruff format --check src/

      - name: 타입 체크
        run: uv run pyright

      - name: 보안 검사
        run: uv run bandit -r src/

      - name: 패키지 취약점 검사
        run: uv run pip-audit

      - name: 단위 테스트
        run: uv run pytest tests/unit/

      - name: 통합 테스트
        run: uv run pytest tests/integration/

      - name: LLM 품질 평가
        run: uv run pytest tests/evaluation/
```
