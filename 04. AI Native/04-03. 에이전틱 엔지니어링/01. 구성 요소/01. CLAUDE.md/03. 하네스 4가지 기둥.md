
## 하네스 엔지니어링의 4가지 기둥

1. **기계가 읽는 컨텍스트 파일** — `CLAUDE.md`, `AGENTS.md` 등 에이전트가 자동 로드하는 규칙/지침
2. **결정론적 CI/CD 게이트** — 린터, Hook, 자동 교정 루프로 AI 출력을 기계가 검증·교정
3. **명시적 도구 경계** — 최소 권한 원칙(least privilege)으로 에이전트가 만질 수 있는 범위를 제한
4. **지속적 피드백 루프** — 가비지 컬렉션 방식의 컨텍스트 정리, 실패를 시스템에 환류

### 에이전틱 엔지니어링의 핵심 5가지

| 개념                  | 한 줄 요약                      |
| ------------------- | --------------------------- |
| Agent & Sub-Agent   | 계층적으로 위임하고 병렬로 실행한다.        |
| Context Engineering | 에이전트에게 줄 정보를 전략적으로 설계한다.    |
| Tool & MCP          | 표준화된 도구로 에이전트의 행동 반경을 넓힌다.  |
| Hook & Skill        | 자동 안전장치와 전문 지식으로 품질을 제어한다.  |
| Planing & HITL      | 계획-실행-검증 루프로 돌리되, 인간이 감독한다. |
