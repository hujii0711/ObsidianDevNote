### Claude Code 전용 셋업

- **`CLAUDE.md` (프로젝트 루트)**: Claude Code가 매번 자동으로 읽는 파일
	‣ 프로젝트 한 줄 설명
	‣ 사용 기술 스택
	‣ 폴더 구조 원칙
	‣ 명명 규칙
	‣ 코드 스타일 핵심 규칙
	‣ **자주 쓰는 명령어** (`npm run dev`, `npm run check` 등)
	‣ **절대 하면 안 되는 것 목록**

> 예시
```markdown
# Project Conventions

## Stack
Next.js 14 (App Router) + TypeScript + Prisma + PostgreSQL
 
## Folder Structure
- `src/features/` : 기능별 모듈
- `src/shared/` : 공통 유틸/컴포넌트
    
## Conventions
- 파일명: kebab-case
- 컴포넌트명: PascalCase
- any 타입 금지, unknown 사용
- default export 금지, named export 사용

## Commands
- 개발: `pnpm dev`
- 검사: `pnpm check`
- 테스트: `pnpm test`
 
## Never Do
- console.log 커밋 금지
- 직접 SQL 작성 금지 (Prisma만 사용)
- 새 의존성 추가 전 반드시 확인 요청
```

- **`docs/` 폴더**: 기획/설계 문서를 모두 여기에
- **샘플 코드 한두 개**: 모범 패턴이 될 컴포넌트/API/테스트 예시

> CLAUDE.md - 자율 개발시 예제

```markdown
# CLAUDE.md - 자율 개발 오케스트레이터

## 🎯 핵심 원칙
1. 개발자 입력 최소화 - 한 줄 요청으로 전체 파이프라인 실행
2. Lazy Loading - 필요한 문서만 그때그때 참조
3. Todo 추적 - 모든 진척을 TODO.md에 실시간 기록
4. 자가 복구 - 에러 발생 시 자동 수정 3회 시도
5. 실패 격리 - 어느 단계든 실패 시 즉시 중단 후 보고

## 📚 문서 참조 규칙 (Lazy Loading)

### 시작 시 항상 읽는 문서
- `docs/index.md` (목차)

### 트리거 기반 자동 참조
| 키워드 | 자동 로드 문서 |
|--------|--------------|
| 인증/로그인/회원 | docs/features/auth.md |
| 결제/환불/구독 | docs/features/payment.md |
| DB/스키마/마이그레이션 | docs/architecture/database.md |
| API/엔드포인트 | docs/architecture/api.md |
| 테스트/spec | docs/conventions/testing.md |
| 보안/취약점 | docs/conventions/security.md |

## 🤖 서브에이전트 실행 규칙

### 파이프라인 순서 (반드시 준수)
```

1. plan-agent → docs/agents/plan-agent.md 참조
2. code-agent → docs/agents/code-agent.md 참조
3. review-agent → docs/agents/review-agent.md 참조
4. test-agent → docs/agents/test-agent.md 참조
5. security-agent→ docs/agents/security-agent.md 참조

```
### 각 에이전트 실행 전 체크
- [ ] 이전 에이전트 결과 확인
- [ ] 필요 문서 Lazy Load
- [ ] TODO.md 상태 업데이트

### 자가 복구 규칙
- lint 에러: `npm run lint:fix` 자동 실행 (최대 3회)
- 타입 에러: 에러 메시지 분석 후 자동 수정
- 테스트 실패: 실패 원인 분석 후 코드 수정 1회 시도
- 보안 이슈: 자동 수정 금지 → 반드시 사용자 보고

## 📋 Todo 관리 규칙
- 작업 시작: `bash scripts/todo-manager.sh start "항목"`
- 작업 완료: `bash scripts/todo-manager.sh done "항목"`
- 작업 실패: `bash scripts/todo-manager.sh fail "항목" "이유"`
- 진척률 10% 변화마다 출력

## 🔒 절대 금지 사항
- 보안 에이전트 생략 금지
- 테스트 실패 상태로 PR 생성 금지
- 하드코딩된 시크릿 커밋 금지
- docs/ 전체 일괄 로딩 금지
```

### 자동화 기본 플로우

```
개발자: "결제 환불 기능 추가해줘" (한 줄 입력)
                    ↓
    ┌───────────────────────────────┐
    │     오케스트레이터 (CLAUDE.md)    │
    └───────────────────────────────┘
           ↓          ↓          ↓
    [Lazy Doc]  [Todo 관리]  [Git Worktree]
           ↓
    ┌──────────────────────────────────────┐
    │  Plan → Code → Review → Test → Sec   │
    └──────────────────────────────────────┘
           ↓
    GitHub Issue → PR → Merge ✅
```
