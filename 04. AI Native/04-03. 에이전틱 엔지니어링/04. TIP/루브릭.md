
# 하네스 엔지니어링 루브릭 적용

## 클로드 코드란?

클로드 코드는 전체 코드베이스를 읽고, 여러 파일에 걸쳐 계획을 수립하고, 변경을 실행하며, 테스트를 실행하고, 실패 시 반복 개선하는 에이전틱(Agentic) 코딩 시스템입니다. 하네스 엔지니어링에서는 이 AI 도구를 활용해 루브릭 기반의 평가·검증 자동화 시스템을 구축할 수 있습니다.

---

## 하네스 엔지니어링에서 클로드 코드 활용 구조

```
하네스 설계 데이터 (CAD/BOM/도면)
        ↓
  Claude Code 루브릭 엔진
        ↓
  자동 평가 & 피드백 리포트
        ↓
  엔지니어 검토 & 승인
```

---

## 주요 활용 분야 및 루브릭 적용 방법

### 1. 설계 검증 자동화 루브릭

클로드 코드에게 설계 파일(CSV, JSON, XML)을 제공하고, 아래와 같은 루브릭 기준으로 자동 채점하도록 프롬프트를 구성합니다.

**예시 프롬프트 구조:**

```
다음 하네스 BOM 데이터를 아래 루브릭 기준으로 평가하라:

[루브릭 기준]
- 커넥터 전류 용량: 정격의 80% 이하 → 4점 / 80~90% → 3점 / ...
- 배선 단면적 선택: AWG 표준 완전 준수 → 4점 / ...
- 접지 경로 연속성: 모든 경로 확인 → 4점 / ...

각 항목을 점수화하고, 미달 항목에 대해 수정안을 제시하라.
```

**루브릭 자동 평가 결과 예시:**

|항목|점수|판정|클로드 코드 피드백|
|---|---|---|---|
|커넥터 전류 용량|4/4|✅ 우수|기준 충족|
|배선 단면적|2/4|⚠️ 보통|A-03 구간 AWG 재검토 필요|
|접지 경로|3/4|🔵 양호|GND-7 경로 임피던스 확인 권장|

---

### 2. 코드 기반 품질 검사 루브릭

하네스 테스트 자동화 스크립트(Python/C++)를 클로드 코드로 작성할 때, 루브릭을 코드 품질 기준으로 활용합니다.

**루브릭 적용 예:**

|코드 품질 항목|4 (우수)|3 (양호)|2 (보통)|1 (미흡)|
|---|---|---|---|---|
|도통 검사 커버리지|전 핀 100%|주요 핀 95%+|80%+|80% 미만|
|오류 처리 로직|모든 예외 처리|주요 예외 처리|일부 처리|미처리|
|실행 속도|목표 대비 ±5%|±10%|±20%|초과|
|코드 가독성|주석·문서 완비|대부분 문서화|일부 문서화|미문서화|

엔지니어는 목표를 정의하고 결과를 검토하며, 각 단계를 직접 지시하는 대신 클로드 코드가 실행을 담당합니다.

---

### 3. FMEA(고장 모드 영향 분석) 루브릭 자동화

```python
# Claude Code에게 지시하는 루브릭 기반 FMEA 자동화 예시
"""
하네스 FMEA 데이터를 분석하고 다음 루브릭으로 리스크를 평가하라:

심각도(S) 루브릭:
  4점: 안전 관련 고장 (차량 제어 불능)
  3점: 주요 기능 손실
  2점: 성능 저하
  1점: 경미한 불편

발생도(O) 루브릭:
  4점: 1,000개당 1개 이상
  3점: 10,000개당 1개
  2점: 100,000개당 1개
  1점: 거의 없음

검출도(D) 루브릭:
  4점: 검출 불가
  3점: 검출 어려움
  2점: 검출 가능
  1점: 확실히 검출

RPN = S × O × D 를 계산하고 우선순위를 정렬하라.
"""
```

## 클로드 코드 활용의 핵심 장점

### ✅ 대규모 데이터 일괄 평가

클로드 코드는 프로젝트 구조와 의존성을 파악하기 위해 에이전틱 검색을 사용해 수 초 안에 전체 코드베이스를 파악합니다. 수백 개의 하네스 도면을 동시에 루브릭 기준으로 평가할 수 있습니다.

### ✅ 반복적 개선 루프

테스트가 실패하면 클로드 코드는 오류를 읽고 코드를 수정하며 모든 것이 통과될 때까지 다시 실행합니다. 루브릭 미달 항목에 대해 수정 후 재평가를 자동으로 반복합니다.

### ✅ 비엔지니어도 활용 가능

제품 관리자, 창업자, 운영 팀이 결과를 자연어로 설명하는 것만으로 작동하는 도구를 만들기 시작했습니다. 루브릭만 잘 정의하면 비전문가도 품질 평가 시스템을 운용할 수 있습니다.

### ✅ 안전한 검토 프로세스

기본값은 신중합니다: 클로드 코드는 파일을 변경하거나 명령을 실행하기 전에 먼저 확인을 요청합니다. 하네스 설계 변경 전 반드시 엔지니어 승인 단계를 거칩니다.

## 실제 적용 워크플로우

```
1단계: 루브릭 정의
   └─ 평가 항목, 점수 기준, 합격/불합격 임계값 문서화

2단계: 클로드 코드에 루브릭 탑재
   └─ CLAUDE.md 파일에 하네스 평가 기준 내장

3단계: 설계 데이터 입력
   └─ BOM, 도면, 테스트 결과 파일 제공

4단계: 자동 루브릭 평가 실행
   └─ 항목별 점수화 + 미달 원인 분석

5단계: 리포트 생성 & 엔지니어 검토
   └─ PDF/Excel 리포트 자동 생성

6단계: 수정 후 재평가 (반복)
   └─ 기준 충족 시까지 루프
```

## 도입 시 주의사항

- **루브릭의 품질이 결과를 결정합니다** — 평가 기준을 명확하고 구체적으로 정의해야 합니다
- **최종 판단은 엔지니어가** — AI 평가 결과는 보조 도구이며, 안전 관련 항목은 반드시 인간이 검토해야 합니다
- **도메인 데이터 형식 표준화** — 클로드 코드가 읽을 수 있도록 BOM/도면 데이터를 구조화된 형식으로 관리해야 합니다

클로드 코드와 루브릭의 결합은 하네스 엔지니어링에서 **품질 평가의 속도, 일관성, 추적 가능성**을 크게 향상시킬 수 있습니다.하네스 엔지니어링 루브릭 시스템 구축에 클로드 코드를 직접 활용하고 싶으시다면 위 도구들을 참고해 보세요. 터미널 CLI나 VS Code 확장 중 편하신 환경에서 시작하실 수 있습니다.
