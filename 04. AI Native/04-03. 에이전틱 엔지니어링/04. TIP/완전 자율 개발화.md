### 자율화 성숙도 단계

```
Lv.1  수동       개발자가 직접 모든 단계 실행
Lv.2  반자동     Claude Code가 코드 생성, 나머지 수동
Lv.3  파이프라인  스크립트로 단계 자동화 (지금 단계)
Lv.4  자율       이슈 라벨만 달면 PR까지 자동
Lv.5  완전자율   이슈 생성도 자동 (모니터링 기반)
```

### 핵심 요약

|구성 요소|역할|
|---|---|
|`CLAUDE.md`|전체 규칙과 트리거 정의|
|`docs/index.md`|Lazy Loading 목차|
|`TODO.md`|실시간 진척 추적|
|`orchestrator.sh`|전체 파이프라인 진입점|
|`5개 에이전트`|각 단계 전문화 처리|
|`GitHub Actions`|이슈 → PR 완전 자동화|
|`Git Worktree`|격리된 작업 환경|

**한 줄 입력 → GitHub PR 자동 생성**이 최종 목표이며, CLAUDE.md가 이 시스템의 두뇌 역할을 합니다.
