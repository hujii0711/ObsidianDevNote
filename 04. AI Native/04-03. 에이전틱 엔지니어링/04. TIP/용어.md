
- 펜아웃
	"하나의 큰 과제를 여러 개의 작은 작업으로 쪼개어 여러 서브에이전트에게 동시에 병렬로 뿌려주는 일대다(1:N) 분산 처리 방식"을 뜻합니다.
	
- 펜인
	**여러 갈래로 흩어졌던 작업의 결과를 다시 하나로 모으는 다대일(N:1) 수렴 처리 방식**을 뜻합니다.
	
- 핸드오프
	"자신이 하던 작업이나 제어권을 더 적합한 다른 주체(시스템, 도구, 사람)에게 넘겨주는 행 위"를 의미합니다. 스포츠에서 이어달리기를 할 때 바톤을 넘겨주거나, 미식축구에서 쿼터백이 러닝백에게 공을 건네주는 모습을 상상하시면 이해하기 쉽습니다.
	
- 스폰
	'스폰(Spawn)'은 개발 및 시스템 아키텍처 분야에서 사용하는 용어로, "메인 에이전트(Claude)가 특정 역할을 수행할 독립된 하위 프로세스(서브에이전트)를 새로 생성하여 실행한다"는 의미입니다.
	여기서 '스폰한다'는 것은 **"메인 AI가 특정 단계의 작업을 처리하기 위해, 독립된 하위 전문 AI를 새롭게 만들어 화면에 올리고(실행시키고) 일을 맡긴다"**는 뜻입니다.
	💡릴레이(바톤 터치) 방식의 업무: 서브에이전트끼리 소통이 안 되기 때문에, 메인 Claude가 `A 에이전트 스폰` ➔ `A가 결과물을 공유 파일(_workspace/)에 저장 후 종료` ➔ `메인 Claude가 확인 후 B 에이전트 스폰` ➔ `B가 파일 이어받아 작업`하는 방식으로 일을 진행합니다. 이 모든 규칙의 중심(단일 출처)이 바로 `shopping-mall-builder`라는 스킬인 것입니다.
	
- RSC(React Server Component)
	서버에서만 렌더링되는 React 컴포넌트입니다. 브라우저로 JavaScript 번들이 전송되지 않고, 서버에서 렌더링된 결과만 클라이언트로 보내집니다.
	
- 플러그인
	Claude Code를 확장하는 자체 포함 디렉터리.
	skill, agent, command, hook, MCP Server, LSP Server 등을 한 묶음으로 패키징해 버전 관리 + 마켓플레이스 배포가 가능하게 만든 것이다.
	플러그인은 새로운 구성요소가 아니다. 이미 익숙한 skill, agent, hook을 한 폴더에 모아 manifest로 묶은 것일 뿐이다.
