
안티그래비티(Antigravity)를 터미널 CLI에서 구동하는 올바른 명령어는 `agv`가 아니라 **`agy`** 입니다.

터미널에서 사용할 수 있는 주요 실행 방법 및 옵션은 다음과 같습니다.

---

### 1. 기본 실행 (대화형 터미널)
프로젝트 디렉터리로 이동한 후 아래 명령어를 입력하면 에이전트와 실시간 대화가 가능한 인터랙티브(REPL) 모드가 실행됩니다.
```bash
agy
```

---

### 2. 주요 옵션 및 플러그 (Flags)

* **직전 대화 이어하기 (`-c` / `--continue`)**
  가장 최근에 진행하던 에이전트 대화 맥락을 이어서 시작합니다.
  ```bash
  agy -c
  ```

* **일회성 질문 던지고 바로 종료하기 (`-p` / `--print`)**
  에이전트 화면을 띄우지 않고 단발성 질문에 대한 답변만 터미널에 바로 출력하고 종료합니다.
  ```bash
  agy -p "현재 프로젝트 구조를 간략히 표로 정리해줘"
  # 또는 agy --prompt "..."
  ```

* **첫 질문을 던지며 대화 시작하기 (`-i` / `--prompt-interactive`)**
  특정 질문으로 에이전트 세션을 시작하고, 그 상태에서 계속 이어서 대화합니다.
  ```bash
  agy -i "pipelines의 ruff 검사를 먼저 수행해줘"
  ```

* **자동 권한 승인 모드 (`--dangerously-skip-permissions`)**
  에이전트가 도구 실행 및 파일 쓰기 권한을 매번 팝업창으로 물어보지 않고 자동으로 전부 승인하도록 실행합니다.
  ```bash
  agy --dangerously-skip-permissions
  ```

---

### 3. 유용한 서브커맨드 (Subcommands)

* **사용 가능한 AI 모델 목록 조회**
  ```bash
  agy models
  ```

* **플러그인/스킬 관리 (`plugin`)**
  설치된 플러그인 확인 및 관리를 처리합니다.
  ```bash
  agy plugin list
  ```

* **환경 설정 및 쉘 초기화**
  경로 설정이나 자동완성 쉘 설정을 복구하고 싶을 때 사용합니다.
  ```bash
  agy install
  ```

* **CLI 버전 업데이트**
  ```bash
  agy update
  ```
