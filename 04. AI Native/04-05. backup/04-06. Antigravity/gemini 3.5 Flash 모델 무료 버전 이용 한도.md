
Google AI Studio 및 Gemini API 기준, **Gemini 3.5 Flash** (및 유사 Flash 모델군) 무료 버전의 하루 이용 한도 및 상세 제한 사양은 다음과 같습니다.

---

### 1. 무료 버전 일일 한도 (Quotas)
무료 티어는 개발, 프로토타이핑 및 소규모 테스트용으로 제공되며, 프로젝트당 다음과 같은 기본 한도가 적용됩니다.

* **일일 요청 한도 (Requests Per Day - RPD)**: 하루 최대 **1,500회**
* **분당 요청 한도 (Requests Per Minute - RPM)**: 분당 **10 ~ 15회** (약 4~6초에 1번 꼴)
* **분당 토큰 한도 (Tokens Per Minute - TPM)**: 분당 최대 **1,000,000 토큰** (100만 토큰)

---

### 2. 무료 버젼 이용 시 주의할 점
1. **데이터 활용 조항 (Privacy)**:
   * 무료 버전을 사용할 경우, 사용자가 입력한 프롬프트와 에이전트의 답변 데이터가 **Google의 모델 성능 향상 및 품질 개선 연구를 위해 수집 및 검토**될 수 있습니다. 회사 기밀이나 개인 정보 등 민감한 데이터는 입력하지 않는 것이 안전합니다.
2. **결제 계정 등록 시 주의**:
   * Google Cloud 프로젝트에 신용카드/결제(Billing) 계정을 연동하는 순간, 해당 프로젝트의 무료 티어 혜택이 즉시 종료되고 사용한 만큼 요금이 청구되는 paid(Pay-as-you-go) 모드로 전환됩니다. (별도의 무료 전용 프로젝트를 유지하는 것을 권장합니다.)
3. **한도 초과 시**:
   * 한도를 초과하면 `429: Resource Exhausted` 에러가 발생합니다. 이 경우 대기 시간이 지난 후 순차적으로 다시 요청을 처리해야 합니다.

---

### 3. 실시간 정확한 한도 확인 방법
계정 및 프로젝트 상태에 따른 실시간 한도는 [Google AI Studio](https://aistudio.google.com/)에 로그인하신 후 **Settings(설정) > Quota / Rate Limits(할당량)** 메뉴에서 언제든지 가장 정확하게 확인하실 수 있습니다.

# gemini 3.5 Flash 모델 유료 버전 이용 한도 정책


Gemini API(Google AI Studio) 유료 요금제(Pay-as-you-go)로 전환 시 적용되는 **이용 한도(Rate Limit) 및 등급 정책**은 다음과 같이 운영됩니다.

---

### 1. 사용 등급제 (Usage Tiers) 정책
유료 결제(Billing) 계정을 연결하면 결제 누적 금액 및 기간에 따라 사용자의 등급(Tier)이 자동으로 올라가며 한도가 대폭 상향됩니다.

| 등급 (Usage Tier) | 조건 (Qualification) | 주요 혜택 및 한도 수준 |
| :--- | :--- | :--- |
| **무료 (Free)** | 기본 회원 / 테스트용 | 하루 1,500회 제한, **학습 데이터 수집 대상** |
| **Tier 1** | 유료 결제 계정(Billing) 최초 연동 시 | **150~300 RPM** (분당 요청), 실서비스 사용 가능 |
| **Tier 2** | 누적 결제액 $100 이상 + 결제 시작 3일 경과 | Tier 1보다 한층 더 높은 RPM / TPM 제공 |
| **Tier 3** | 누적 결제액 $1,000 이상 + 결제 시작 30일 경과 | 대규모 프로덕션을 위한 최고 한도 제공 |

*※ 등급이 올라갈수록 분당 요청 수(RPM)와 분당 토큰 처리량(TPM) 한도가 대폭 넓어집니다.*

---

### 2. 세 가지 기준으로 측정되는 이용 한도 (Rate Limit)
유료 버전에서도 다음 3가지 기준을 통해 실시간으로 한도를 모니터링하며, 어느 하나라도 초과 시 `429 (Resource Exhausted)` 에러가 발생합니다.

1. **RPM (Requests Per Minute)**: 분당 호출할 수 있는 최대 API 요청 수
2. **TPM (Tokens Per Minute)**: 분당 처리할 수 있는 최대 토큰 수 (프롬프트 입력 + 답변 출력의 합)
3. **RPD (Requests Per Day)**: 하루에 요청할 수 있는 총 API 요청 수 (태평양 표준시 P.S.T 기준 자정에 리셋)

---

### 3. 유료 요금제 사용 시 핵심 장점 및 특징
* **데이터 프라이버시 보장 (중요)**:
  무료 버전과 달리, **유료 요금제를 사용할 경우 사용자가 입력하는 데이터(프롬프트)와 모델이 생성하는 답변은 절대 Google의 모델 학습용 데이터로 수집되거나 활용되지 않습니다.** 기업 내부 정보나 민감한 데이터를 다루는 경우 필수적인 조건입니다.
* **프로젝트 단위 한도 공유**:
  한도는 API 키 개수가 아닌 **Google Cloud 프로젝트 단위**로 관리됩니다. 하나의 프로젝트 아래에서 API 키를 여러 개 발급하더라도, 해당 프로젝트 전체가 한도(RPM/TPM/RPD)를 나누어 쓰게 됩니다.
* **비용 절감 기술 지원**:
  유료 버전에서는 대량 비동기 작업을 위한 **Batch API**(비용 50% 절감) 및 반복적이고 긴 지침을 캐싱하여 비용을 아끼는 **Context Caching** 기능을 제공하여 비용 효율성을 더욱 높일 수 있습니다.

---

### 4. 내 계정의 실시간 한도 확인법
구체적이고 정확한 실시간 수치는 [Google AI Studio](https://aistudio.google.com/)의 **Plan details(요금제 상세)** 혹은 **Rate Limits(할당량)** 탭에서 현재 소속 프로젝트의 Tier와 할당량 현황을 실시간으로 확인하실 수 있습니다.
