
### 1. 이슈 등록

```bash
gh issue create \
  --title "feat: 로그인 기능 구현" \
  --body "이메일/비밀번호 로그인 기능 구현" \
  --label "feature" \
  --assignee "@me"
```


### 2. 브랜치 생성 및 작업

```bash
# 워크트리 생성 (이슈 번호 42 기준)
git worktree add .claude/worktrees/feature-42 -b feature/#42-login

# 워크트리로 이동
cd .claude/worktrees/feature-42

# 작업 후 커밋
git add .
git commit -m "feat: 로그인 기능 구현"

# 원격 브랜치로 push
git push origin feature/#42-login
```


### 3. 이슈 번호 확인 방법

```bash
# 현재 저장소 이슈 목록
gh issue list

# 특정 이슈 상세 확인
gh issue view 42
```


### 4. 브라우저 열기
``` bash
# 이슈 생성과 동시에 브라우저로 해당 이슈 페이지를 엽니다.
gh issue create --title "새로운 이슈" --body "내용" --web

# 예: 15번 이슈를 웹에서 확인
gh issue view 15 --web
```
