
- 팀원들이 리더를 거치지 않고 서로 직접 대화할 수 있게 해주는 세 가지 도구: TeamCreate(팀을 구성하는 도구), TaskCrete(할 일을 만들고 추적하는 도구), SendMessage(팀원들이 서로 메시지를 주고 받는 도구)

| 프로토콜  | 도구                    | 지원하는 패턴                 | 적합한 상황                  |
| ----- | --------------------- | ----------------------- | ----------------------- |
| 구성    | TeamCrete + Agent     | 팀 구성, 역할 부여, 통신 대상 생성   | 세션 초기에 팀을 구성할 때         |
| 태스크   | TaskCreate/TaskUpdate | 공유 작업 큐, 의존성 관리, 진행률 보고 | 여러 작업을 나누고 조율할 때        |
| 메시지   | SendMessage           | 팀원 간 직접 메시지             | 발견 사항 공유, 상호 참조, 짧은 피드백 |
| 파일 규약 | `_workspace/*,md`     | 대용량 산출물 저장, 단계 간 인계     | 중간 산출물을 저장. 교환할 때       |
