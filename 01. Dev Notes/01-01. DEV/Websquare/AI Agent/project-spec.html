01정체와 계보

웹스퀘어 개발자가 IDE나 웹 UI에서 AI 에이전트를 호출해 화면 소스 이해·수정과 TestSquare E2E 테스트 코드 생성을 자동화하도록, qwen-code를 소켓 서버로 재포장하고 인스웨이브 환경에 맞게 경로·권한·프롬프트를 바꾼 프로젝트다. 에이전트 브랜드명은 AI Talk Plus.

이 포크가 직접 수정한 저장소 루트 파일

  • package.json — workspaces를 core·cli·api-server 셋으로 축소, prepare를 비워 husky 훅 비활성화, postinstall에 npm audit fix --audit-level=none 추가

core에 대한 변경은 전부 빌드타임 패치로 처리한다(§07). 원본을 건드리지 않으므로 upstream 새 버전을 충돌 없이 당겨올 수 있다.

에이전트에 허용된 core 도구는 파일 조작 7종뿐이다. 즉 파일을 읽고 쓰는 것 외의 모든 능력은 MCP를 통해서만 들어온다. 그리고 DeepSquare.md 7장이 요구하는 입력은 파일시스템을 뒤져서 나오는 게 아니다.

  • test-plan.md — 화면 ID, 시나리오 목록, 우선순위, 관련 API 엔드포인트
