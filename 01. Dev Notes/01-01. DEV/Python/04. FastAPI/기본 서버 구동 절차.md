
# uv로 맥에서 FastAPI 프로젝트 만들기

uv는 가상환경 생성, 패키지 설치, 실행을 한 도구로 처리합니다. 앞서 설명한 `python3 -m venv`, `source activate`, `pip install` 과정이 대부분 필요 없어지고, **가상환경을 직접 활성화하지 않아도 됩니다.**

## 1단계: uv 확인

```bash
uv --version
```

명령이 없다면 아래 중 하나로 설치합니다.

```bash
brew install uv
# 또는
curl -LsSf https://astral.sh/uv/install.sh | sh
```

이미 설치되어 있다면 `uv self update`(공식 스크립트로 설치한 경우) 또는 `brew upgrade uv`(Homebrew로 설치한 경우)로 최신 상태를 유지하세요.

## 2단계: 프로젝트 생성

```bash
uv init my-fastapi-app
cd my-fastapi-app
```

이미 만들어 둔 폴더에서 시작하려면 폴더 안에서 `uv init`만 실행하면 됩니다. 생성되는 파일은 다음과 같습니다.

```
my-fastapi-app/
├── .git/                # git 저장소 (자동 초기화)
├── .gitignore           # .venv 등이 이미 포함됨
├── .python-version      # 사용할 파이썬 버전
├── README.md
├── main.py              # 샘플 파일 (곧 덮어쓸 예정)
└── pyproject.toml       # 프로젝트 설정 및 의존성 목록
```

특정 파이썬 버전을 쓰고 싶다면 이렇게 지정합니다. 해당 버전이 없으면 uv가 알아서 내려받습니다.

```bash
uv init my-fastapi-app --python 3.12
```

## 3단계: FastAPI 설치

```bash
uv add "fastapi[standard]"
```

이 명령 하나로 다음 작업이 자동으로 이루어집니다.

- `.venv` 가상환경이 없으면 프로젝트 폴더 안에 생성
- FastAPI, Uvicorn, Pydantic 등 설치
- `pyproject.toml`의 `dependencies`에 기록
- `uv.lock` 파일에 정확한 버전 고정

따옴표는 여전히 필요합니다. zsh가 `[standard]`를 특수 문자로 해석하기 때문입니다.

설치된 패키지는 이렇게 확인합니다.

```bash
uv pip list
# 의존성 트리를 보려면
uv tree
```

## 4단계: 앱 코드 작성

`uv init`이 만든 `main.py`를 아래 내용으로 **덮어씁니다.**

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}


@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    return {"item_id": item_id, "q": q}
```

VS Code를 쓰신다면 `code main.py`로 열 수 있습니다.

## 5단계: 서버 실행

```bash
uv run fastapi dev main.py
```

`uv run`은 프로젝트의 `.venv`를 자동으로 사용해 명령을 실행하므로 `source .venv/bin/activate`가 필요 없습니다. 다음과 같은 로그가 나오면 성공입니다.

```
Server started at http://127.0.0.1:8000
Documentation at http://127.0.0.1:8000/docs
```

Uvicorn을 직접 실행하는 방식도 가능합니다.

```bash
uv run uvicorn main:app --reload
```

### 매번 파일명을 쓰기 싫다면

`pyproject.toml`에 진입점을 등록하면 `uv run fastapi dev`만으로 실행됩니다. (최신 FastAPI CLI 기준)

```toml
[tool.fastapi]
entrypoint = "main:app"
```

```bash
uv run fastapi dev
```

### 가상환경을 직접 활성화하고 싶다면 (선택)

원한다면 기존 방식대로 활성화해서 쓸 수도 있습니다.

```bash
source .venv/bin/activate
fastapi dev main.py
deactivate
```

## 6단계: 동작 확인

|주소|내용|
|---|---|
|http://127.0.0.1:8000|`{"message":"Hello, FastAPI!"}`|
|http://127.0.0.1:8000/items/5?q=test|경로·쿼리 파라미터|
|http://127.0.0.1:8000/docs|Swagger UI (자동 API 문서)|
|http://127.0.0.1:8000/redoc|ReDoc 문서|

새 터미널 탭에서 `curl`로도 확인할 수 있습니다.

```bash
curl "http://127.0.0.1:8000/items/5?q=test"
```

서버 종료는 `Ctrl + C`입니다.

## 7단계: POST 요청과 데이터 모델 추가

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    price: float
    is_offer: bool = False


@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}


@app.post("/items")
def create_item(item: Item):
    return {"message": "created", "item": item}
```

`/docs`에서 `POST /items`를 열고 **Try it out**을 눌러 아래 JSON으로 테스트해 보세요.

```json
{ "name": "사과", "price": 1500 }
```

## 8단계: 패키지 관리 명령어

|작업|명령어|
|---|---|
|패키지 추가|`uv add sqlalchemy`|
|개발용 패키지 추가|`uv add --dev pytest httpx`|
|패키지 제거|`uv remove sqlalchemy`|
|패키지 업그레이드|`uv lock --upgrade-package fastapi` 후 `uv sync`|
|전체 업그레이드|`uv lock --upgrade` 후 `uv sync`|
|환경 동기화|`uv sync`|
|스크립트 실행|`uv run python script.py`|
|테스트 실행|`uv run pytest`|

`pip freeze > requirements.txt` 과정은 필요 없습니다. 의존성은 `pyproject.toml`과 `uv.lock`이 관리합니다. 다만 배포 환경에서 requirements.txt가 꼭 필요하면 내보낼 수 있습니다.

```bash
uv export --no-hashes -o requirements.txt
```

## 9단계: 다른 컴퓨터에서 환경 복원

프로젝트를 git에서 받은 뒤 폴더에서 이렇게만 하면 됩니다.

```bash
git clone <저장소 주소>
cd my-fastapi-app
uv sync
uv run fastapi dev main.py
```

`uv sync`가 `.python-version`에 맞는 파이썬을 확인하고, `.venv`를 만들고, `uv.lock`에 고정된 버전 그대로 설치합니다. 그래서 `.venv`는 git에 올리지 않고 **`pyproject.toml`, `uv.lock`, `.python-version`은 반드시 올립니다.**

## 10단계: 프로젝트가 커질 때 추천 구조

```
my-fastapi-app/
├── .venv/
├── app/
│   ├── __init__.py
│   ├── main.py          # FastAPI 앱 생성
│   ├── routers/
│   │   ├── __init__.py
│   │   └── items.py
│   ├── models.py
│   └── schemas.py
├── tests/
├── pyproject.toml
├── uv.lock
└── .python-version
```

```python
# app/routers/items.py
from fastapi import APIRouter

router = APIRouter(prefix="/items", tags=["items"])


@router.get("/")
def list_items():
    return [{"name": "사과"}, {"name": "배"}]
```

```python
# app/main.py
from fastapi import FastAPI
from app.routers import items

app = FastAPI()
app.include_router(items.router)
```

실행은 `uv run fastapi dev app/main.py`입니다. 진입점을 등록해 두었다면 `entrypoint = "app.main:app"`으로 바꿔 주세요.

## 참고: pip 스타일로 쓰고 싶다면

`pyproject.toml` 없이 예전 방식으로 가볍게 쓰고 싶을 때는 uv의 pip 호환 모드를 사용할 수 있습니다.

```bash
uv venv
source .venv/bin/activate
uv pip install "fastapi[standard]"
```

이 방식은 `pyproject.toml`과 `uv.lock`을 자동으로 관리하지 않으므로, 새 프로젝트라면 위의 `uv init` + `uv add` 방식을 권장합니다.

## 자주 만나는 문제

- **`No pyproject.toml found` 오류**: `uv init`을 하지 않은 폴더에서 `uv add`를 실행한 경우입니다. 먼저 `uv init`을 실행하세요.
- **`zsh: no matches found: fastapi[standard]`**: 따옴표를 빼먹은 경우입니다. `"fastapi[standard]"`로 입력하세요.
- **`Failed to spawn: fastapi` 또는 `command not found`**: `fastapi[standard]`가 아니라 `fastapi`만 설치했을 가능성이 큽니다. `uv add "fastapi[standard]"`로 다시 설치하세요.
- **`Address already in use`**: 포트가 사용 중입니다. `uv run fastapi dev main.py --port 8001`로 바꾸거나 `lsof -i :8000`으로 확인하세요.
- **VS Code에서 import에 빨간 줄이 뜰 때**: `Cmd + Shift + P` → `Python: Select Interpreter`에서 프로젝트의 `.venv/bin/python`을 선택하세요.
- **파이썬 버전이 맞지 않을 때**: `uv python install 3.12`로 설치한 뒤 `uv python pin 3.12`로 프로젝트 버전을 고정하고 `uv sync`를 실행하세요.
- **같은 네트워크의 다른 기기에서 접속하고 싶을 때**: `uv run fastapi dev main.py --host 0.0.0.0`으로 실행하고 맥의 내부 IP로 접속하세요.

원하시면 SQLite/PostgreSQL 연동, JWT 인증, uv 기반 Docker 배포 같은 다음 단계도 이어서 설명해 드리겠습니다.
