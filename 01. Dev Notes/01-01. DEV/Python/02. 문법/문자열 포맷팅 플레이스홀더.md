
```python
from langchain_core.prompts import ChatPromptTemplate

chat_template = ChatPromptTemplate.from_messages(
	[
		#SystemMessage: 유용한 챗봇이라는 역할과 이름을 부여
		("system", "You are a helpful AI bot. Your name is {name}."),
		
		#HumanMessage와 AIMessage: 서로 안부를 묻고 답하는 대화 히스토리 주입
		("human", "Hello, how are you doing?"),
		("ai", "I'm doing well, thanks!"),
		
		#HumanMessage로 사용자가 입력한 프롬프트를 전달
		("human", "{user_input}"),
	]
)

messages = chat_template.format_messages(name="Bob", user_input="What is your name?")

print(messages)

```

`{name}`은 파이썬의 **문자열 포맷팅 플레이스홀더** 문법이고, LangChain이 이걸 내부적으로 활용해서 템플릿 변수를 처리하는 거예요.

## 동작 원리

**1단계 — 템플릿 정의 시점**

```python
("system", "You are a helpful AI bot. Your name is {name}.")
```

이 문자열 안의 `{name}`은 아직 값이 없는 "빈칸"입니다. 파이썬의 `str.format()` 메서드가 쓰는 표준 문법과 동일해요. 실제로 순수 파이썬만으로 같은 걸 해보면:

```python
template = "Your name is {name}."
template.format(name="Bob")
# 'Your name is Bob.'
```

LangChain의 `ChatPromptTemplate`은 이 문자열을 분석해서 `{name}`, `{user_input}` 같은 중괄호 패턴을 찾아내고, 이걸 **입력 변수(input variables)**로 자동 등록합니다.

**2단계 — `format_messages` 호출 시점**

```python
messages = chat_template.format_messages(name="Bob", user_input="What is your name?")
```

여기서 넘긴 `name="Bob"`은 파이썬 함수의 **키워드 인자(keyword argument)**입니다. `format_messages`는 내부적으로 각 메시지 템플릿을 순회하면서, 발견된 `{name}` 자리에 키워드 인자로 받은 `name` 값을 매칭시켜 채워 넣습니다. 즉 `{변수명}` ↔ `키워드명=값`이 이름으로 매핑되는 구조예요.

## 실제로 벌어지는 일

```
템플릿:   "You are a helpful AI bot. Your name is {name}."
                                                    │
호출:     format_messages(name="Bob", ...)         │
                              └──────────────────────┘
                              같은 이름끼리 매칭

결과:     "You are a helpful AI bot. Your name is Bob."
```

`{user_input}`도 똑같은 방식으로 `user_input="What is your name?"`과 매칭됩니다. 반면 `("human", "Hello, how are you doing?")`이나 `("ai", "I'm doing well, thanks!")`처럼 중괄호가 없는 문자열은 변수가 없으니 그대로 고정된 텍스트로 남습니다.

## 정리

|위치|역할|
|---|---|
|`{name}` (템플릿 안)|값이 채워질 자리 표시자 (플레이스홀더)|
|`name="Bob"` (호출 시)|그 자리에 들어갈 실제 값을 키워드 인자로 전달|
|매칭 방식|중괄호 안 이름 == 키워드 인자 이름 (같아야 함)|

만약 템플릿에 `{name}`이 있는데 `format_messages()` 호출 시 `name=` 인자를 빠뜨리면, `KeyError: 'name'` 같은 에러가 납니다. 즉 템플릿에 정의된 모든 변수는 호출 시 반드시 값을 채워줘야 해요.

---

파이썬 문자열 포맷팅은 여러 방식이 있는데, 하나씩 예제로 볼게요.

## 1. 기본 `{}` — 위치 기반## `.format()` 방식 — LangChain이 쓰는 방식과 동일한 계열

|예제|코드|결과|
|---|---|---|
|위치 기반|`"{}, {}".format("철수", 25)`|`철수, 25`|
|인덱스 재사용|`"{0}는 {1}살, {0}는 학생".format("영희", 20)`|`영희는 20살이고, 영희는 학생입니다`|
|**키워드 매칭**|`"{name}".format(name="민수")`|`민수` ← **이게 LangChain 예제와 동일한 방식**|
|딕셔너리 언패킹|`"{name}".format(**{"name": "지훈"})`|`지훈`|
|소수점 자리수|`"{:.2f}".format(3.14159)`|`3.14`|
|0 패딩|`"{:03d}".format(7)`|`007`|
|천 단위 콤마|`"{:,}".format(1234567)`|`1,234,567`|

## 2. f-string (요즘 더 많이 쓰는 방식)## 3. `%` 포맷팅 (구식이지만 여전히 종종 등장)## 세 방식 비교

|방식|문법|예시|
|---|---|---|
|`%` 포맷팅 (구식)|`%s`, `%d`|`"이름: %s" % name`|
|`.format()`|`{}`, `{name}`|`"이름: {name}".format(name="Bob")`|
|f-string (최신, 권장)|`{변수}`|`f"이름: {name}"`|

**LangChain 코드로 다시 연결하면:**

```python
# LangChain 템플릿 정의
"You are a helpful AI bot. Your name is {name}."

# 내부적으로 하는 일 (개념적으로 이렇게 동작)
"You are a helpful AI bot. Your name is {name}.".format(name="Bob")
```

즉 `ChatPromptTemplate`은 문자열 안의 `{name}`을 저장해 뒀다가, `format_messages(name="Bob", ...)`가 호출되는 시점에 파이썬의 `.format()`과 같은 원리로 값을 대입해줍니다. f-string은 변수 선언 시점에 즉시 값이 박히는 반면, `{}`나 `.format()` 방식은 **템플릿을 미리 만들어두고 나중에 값을 채워 넣을 수 있다**는 게 핵심 차이이고, 이 지연 바인딩(lazy binding) 특성 덕분에 LangChain 같은 라이브러리가 "재사용 가능한 프롬프트 템플릿"을 만들 수 있는 거예요.
