파이썬에서 세트(Set)는 수학의 '집합'을 고스란히 코드로 옮겨놓은 듯한 데이터 타입입니다.

가장 큰 특징 두 가지는 "중복을 허용하지 않는다"와 "순서가 없다(Unordered)"라는 점입니다. 이 특징을 활용하면 데이터 정형화나 집합 연산을 할 때 매우 유용합니다.

## 1. Set 생성하기

세트는 중괄호 `{}`를 사용하거나 `set()` 함수를 사용해 만듭니다.

```python
# 1. 중괄호로 생성
my_set = {1, 2, 3, 3, 3}
print(my_set)  # 출력: {1, 2, 3} (중복된 3은 자동으로 제거됨)

# 2. 리스트를 세트로 변환 (중복 제거할 때 대박 유용!)
my_list = ["apple", "banana", "apple", "cherry"]
unique_set = set(my_list)
print(unique_set)  # 출력: {'banana', 'cherry', 'apple'} (순서는 무작위)

# ⚠️ 주의: 빈 세트를 만들 때는 반드시 set()을 써야 합니다.
empty_dict = {}      # 이것은 빈 '딕셔너리'가 됩니다.
empty_set = set()    # 이것이 진짜 빈 '세트'입니다.
```

## 2. 값 추가 및 삭제 (기본 수정)

세트는 리스트와 달리 순서(인덱스)가 없기 때문에 `append()`나 `pop(0)` 같은 메서드를 쓸 수 없습니다. 대신 전용 메서드가 존재합니다.

```python
s = {1, 2, 3}

# ① 값 하나 추가하기: .add()
s.add(4)
print(s)  # {1, 2, 3, 4}

# ② 값 여러 개 추가하기: .update()
s.update([5, 6, 7])
print(s)  # {1, 2, 3, 4, 5, 6, 7}

# ③ 특정 값 삭제하기: .remove() 또는 .discard()
s.remove(3)     # 3을 삭제 (만약 3이 없으면 KeyError 에러 발생)
s.discard(99)   # 99를 삭제 (값이 없어도 에러 없이 안전하게 넘어감)
print(s)  # {1, 2, 4, 5, 6, 7}
```

## 3. 강력한 기능: 집합 연산

Set의 진가는 교집합, 합집합, 차집합을 구할 때 발휘됩니다. 수학 기호(연산자)나 메서드 둘 다 사용 가능합니다.

```python
set_a = {1, 2, 3, 4, 5}
set_b = {4, 5, 6, 7, 8}

# ① 교집합 (둘 다 있는 것)
print(set_a & set_b)          # 출력: {4, 5}
print(set_a.intersection(set_b))

# ② 합집합 (전체 합치기)
print(set_a | set_b)          # 출력: {1, 2, 3, 4, 5, 6, 7, 8}
print(set_a.union(set_b))

# ③ 차집합 (A에서 B를 빼기)
print(set_a - set_b)          # 출력: {1, 2, 3}
print(set_a.difference(set_b))

# ④ 대칭차집합 (서로 겹치지 않는 나머지 전체)
print(set_a ^ set_b)          # 출력: {1, 2, 3, 6, 7, 8}
```

## 4. 언제 Set을 쓰면 좋을까요?

- **데이터의 중복을 빠르게 제거해야 할 때:** 리스트를 `set()`에 넣었다가 다시 `list()`로 바꾸는 테크닉은 파이썬에서 단골로 쓰입니다.
    
- **특정 값이 포함되어 있는지 확인할 때:** 리스트에서 `if "apple" in my_list:`를 쓰면 처음부터 끝까지 다 찾아봐야 해서 속도가 느릴 수 있지만, 세트는 내부 구조(해시 테이블) 특성상 데이터가 아무리 많아도 **눈 깜짝할 사이에(`O(1)`) 찾아냅니다.**
