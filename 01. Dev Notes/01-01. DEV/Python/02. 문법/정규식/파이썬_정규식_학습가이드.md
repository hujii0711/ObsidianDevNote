## 0. 시작하기 전에 — raw string을 쓰는 이유

```python
import re
```

정규식 패턴은 항상 `r"..."` (raw string)로 작성하는 것이 관례입니다.

```python
r"\d+"   # 권장: 백슬래시가 파이썬 문자열 이스케이프로 해석되지 않음
"\d+"    # \d는 파이썬에 없는 이스케이프라 우연히 동작하지만, \n, \t 등은 다르게 해석되어 버그의 원인이 됨
```

## 1. 기본 메타문자

| 패턴 | 의미 | 예시 (`re.search`) | 결과 |
|---|---|---|---|
| `.` | 줄바꿈을 제외한 임의의 문자 1개 | `.` on `"a"` | `a` |
| `^` | 문자열 시작 | `^Hello` on `"Hello world"` | `Hello` |
| `$` | 문자열 끝 | `world$` on `"Hello world"` | `world` |
| `*` | 앞 패턴 0개 이상 | `a*` on `"aaab"` | `aaa` |
| `+` | 앞 패턴 1개 이상 | `a+` on `"aaab"` | `aaa` |
| `?` | 앞 패턴 0개 또는 1개 | `a?` on `"b"` | `''` (빈 문자열, 매칭은 됨) |
| `{n,m}` | 앞 패턴 n~m개 | `a{2,3}` on `"aaaa"` | `aaa` |

```python
import re
m = re.search(r"a{2,3}", "aaaa")
print(m.group())  # 'aaa' — 탐욕적으로 최대(3개)까지 먼저 시도
```

## 2. 문자 클래스 `[...]`와 축약형

| 패턴 | 의미 |
|---|---|
| `[abc]` | a, b, c 중 하나 |
| `[^abc]` | a, b, c가 **아닌** 문자 (`^`가 대괄호 맨 앞이면 부정) |
| `[a-z]` | 소문자 범위 |
| `[A-Za-z0-9]` | 영문 대소문자 + 숫자 |
| `\d` | 숫자 (`[0-9]`와 동일) |
| `\D` | 숫자가 아닌 것 |
| `\w` | 단어 문자 (`[A-Za-z0-9_]`와 동일, 한글도 포함됨) |
| `\W` | 단어 문자가 아닌 것 |
| `\s` | 공백 문자 (스페이스, 탭, 줄바꿈 등) |
| `\S` | 공백이 아닌 것 |

```python
print(re.findall(r"\d", "abc123"))   # ['1', '2', '3']
print(re.findall(r"\w", "hi_23!"))   # ['h', 'i', '_', '2', '3']
```

> ⚠️ **주의**: `^`는 두 가지 뜻이 있습니다. 문자열 맨 앞에 단독으로 오면 "시작"을, 대괄호 `[^...]` 안 맨 앞에 오면 "부정"을 의미합니다.

## 3. 그룹 `(...)` — 캡처와 재사용

### 3-1. 번호로 접근

```python
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "2026-08-22")
print(m.group(0))   # '2026-08-22'  (전체)
print(m.group(1))   # '2026'        (첫 번째 그룹)
print(m.groups())   # ('2026', '08', '22')  (전체 그룹 튜플)
```

### 3-2. 이름 붙은 그룹 `(?P<이름>...)`

번호 대신 이름으로 접근하면 코드 가독성이 좋아집니다.

```python
m = re.search(r"(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})", "2026-08-22")
print(m.group("y"))     # '2026'
print(m.groupdict())    # {'y': '2026', 'm': '08', 'd': '22'}
```

### 3-3. 비캡처 그룹 `(?:...)`

그룹으로 묶어서 수량자를 적용하고 싶지만, 결과에는 포함시키고 싶지 않을 때 사용합니다.

```python
m = re.search(r"(?:\d{4})-(\d{2})", "2026-08")
print(m.groups())   # ('08',)  ← 앞 (?:...)는 그룹 번호도 안 받고 결과에도 안 나옴
```

## 4. 탐욕적(greedy) vs 게으른(lazy) 수량자

기본 수량자(`*`, `+`, `{n,m}`)는 **탐욕적**이라 가능한 한 많이 매칭합니다. 뒤에 `?`를 붙이면 **게으르게** 최소한만 매칭합니다.

```python
text = "<a><b>"
print(re.search(r"<.+>", text).group())    # '<a><b>'  (탐욕적: 최대한 넓게)
print(re.search(r"<.+?>", text).group())   # '<a>'     (게으른: 최소한만)
```

HTML/XML 태그처럼 중첩된 괄호 구조를 다룰 때 자주 실수하는 지점입니다.

## 5. 경계(`\b`, `\B`)

```python
print(re.findall(r"\bcat\b", "cat category cats cat"))
# ['cat', 'cat']  — "category", "cats"의 일부인 "cat"은 제외됨

print(re.findall(r"\Bcat", "concatenate"))
# ['cat']  — 단어 중간에 낀 "cat"만 찾음
```

`\b`는 단어 문자(`\w`)와 비단어 문자의 경계 지점을 뜻합니다. 정확히 "단어 하나"만 찾고 싶을 때 필수적입니다.

## 6. 전방탐색(lookahead) / 후방탐색(lookbehind)

매칭 결과에는 포함되지 않지만, 특정 패턴이 앞/뒤에 있어야만 매칭되도록 조건을 거는 문법입니다.

| 패턴 | 이름 | 의미 |
|---|---|---|
| `(?=...)` | 긍정 전방탐색 | 뒤에 `...`가 있어야 매칭 |
| `(?!...)` | 부정 전방탐색 | 뒤에 `...`가 없어야 매칭 |
| `(?<=...)` | 긍정 후방탐색 | 앞에 `...`가 있어야 매칭 |
| `(?<!...)` | 부정 후방탐색 | 앞에 `...`가 없어야 매칭 |

```python
text = "가격 1000원, 무게 5kg"

# "원" 앞의 숫자만
print(re.findall(r"\d+(?=원)", text))    # ['1000']

# "원"이 뒤에 안 오는 숫자
print(re.findall(r"\d+(?!원)", text))    # ['100', '5']
```

> 💡 두 번째 결과 `['100', '5']`가 `1000` 전체가 아니라 `100`인 이유: `\d+`는 먼저 `1000`을 탐욕적으로 다 먹은 뒤 `(?!원)`을 검사하는데, `1000` 바로 뒤가 `원`이라 실패 → 한 글자씩 줄여가며 재시도(백트래킹)하다가 `100` 뒤의 `0`은 `원`이 아니므로 `100`에서 통과됩니다. lookahead를 쓸 때 흔히 헷갈리는 지점입니다.

```python
# "$" 뒤의 숫자만 (후방탐색)
print(re.findall(r"(?<=\$)\d+", "가격은 $500 입니다"))  # ['500']
```

## 7. 플래그(flags)

| 플래그 | 효과 |
|---|---|
| `re.IGNORECASE` (`re.I`) | 대소문자 구분 안 함 |
| `re.MULTILINE` (`re.M`) | `^`, `$`가 각 줄의 시작/끝에도 매칭 |
| `re.DOTALL` (`re.S`) | `.`이 줄바꿈 문자까지 포함해서 매칭 |

```python
print(re.findall(r"hello", "Hello HELLO hello", re.IGNORECASE))
# ['Hello', 'HELLO', 'hello']

text = "line1\nline2\nline3"
print(re.findall(r"^line\d", text, re.MULTILINE))
# ['line1', 'line2', 'line3']  ← MULTILINE 없으면 'line1'만 잡힘

print(re.search(r"line1.line2", text, re.DOTALL).group())
# 'line1\nline2'  ← DOTALL 없으면 '.'이 줄바꿈을 못 건너뛰어 매칭 실패
```

## 8. `re.compile()`로 미리 컴파일

같은 패턴을 여러 번 쓸 경우, 미리 컴파일해두면 코드가 깔끔해지고 성능도 좋습니다.

```python
PHONE = re.compile(r"01\d-\d{3,4}-\d{4}")

for t in ["010-1234-5678", "011-123-4567", "abc"]:
    m = PHONE.match(t)
    print(t, "->", m.group() if m else "매칭 안됨")
```

## 9. 핵심 함수 정리

| 함수 | 동작 | 반환값 |
|---|---|---|
| `re.match(p, s)` | 문자열 **맨 앞**에서만 시도 | `Match` 또는 `None` |
| `re.search(p, s)` | 문자열 전체에서 **처음 하나** | `Match` 또는 `None` |
| `re.findall(p, s)` | **모든** 매칭 (그룹 있으면 그룹만) | 리스트 |
| `re.finditer(p, s)` | **모든** 매칭 (위치 정보 포함) | `Match` 이터레이터 |
| `re.sub(p, repl, s)` | 매칭을 치환 | 치환된 문자열 |
| `re.subn(p, repl, s)` | 치환 + 치환 횟수 | `(문자열, 횟수)` 튜플 |
| `re.split(p, s)` | 패턴 기준으로 분리 | 리스트 |

### 9-1. `sub` — 문자열 또는 함수로 치환

```python
# 단순 문자열 치환
print(re.sub(r"\d+", "#", "a1b22c333"))   # 'a#b#c#'

# 함수(콜백)로 동적 치환
def double(m: re.Match) -> str:
    return str(int(m.group()) * 2)

print(re.sub(r"\d+", double, "a1b22c333"))  # 'a2b44c666'

# 그룹 재사용: \1, \2 로 순서 바꾸기
print(re.sub(r"(\w+)@(\w+)", r"\2@\1", "user@domain"))  # 'domain@user'

# count로 치환 개수 제한
print(re.sub(r"\d+", "#", "a1b22c333", count=1))  # 'a#b22c333'
```

### 9-2. `split` — 분리

```python
print(re.split(r",\s*", "a, b,  c,d"))
# ['a', 'b', 'c', 'd']

print(re.split(r",\s*", "a, b,  c,d", maxsplit=1))
# ['a', 'b,  c,d']  ← 1번만 분리

# 패턴에 그룹이 있으면 구분자 자체도 결과에 포함됨
print(re.split(r"(,)", "a,b,c"))
# ['a', ',', 'b', ',', 'c']
```

### 9-3. `findall`의 함정 — 그룹이 있으면 전체가 아닌 그룹만 반환

```python
text = "1000원, 2000원"

print(re.findall(r"(\d+)원", text))   # ['1000', '2000']  ← 그룹값만!
print(re.findall(r"\d+원", text))     # ['1000원', '2000원']  ← 그룹 없으면 전체 매칭
```

이 함정 때문에 "전체 매칭 문자열이 필요한데 그룹도 써야 하는" 상황에서는 `finditer`로 `m.group(0)`과 `m.group(1)`을 각각 꺼내는 게 안전합니다.

## 10. 이스케이프가 필요한 특수문자

정규식에서 특별한 의미를 가진 문자를 리터럴로 쓰려면 `\`를 붙여야 합니다.

특수문자 목록: `. ^ $ * + ? { } [ ] \ | ( )`

```python
print(re.findall(r"\.", "3.14"))              # ['.']  마침표 리터럴
print(re.findall(r"\(.*?\)", "함수(인자1, 인자2) 호출"))  # ['(인자1, 인자2)']
```

동적으로 만든 문자열을 패턴에 안전하게 끼워 넣을 때는 `re.escape()`를 씁니다.

```python
user_input = "1+1=2?"
print(re.escape(user_input))  # '1\\+1\\=2\\?'  ← 특수문자 자동 이스케이프
```

## 11. 실무 자주 쓰는 패턴 모음

```python
patterns = {
    "이메일":     r"[\w.+-]+@[\w-]+\.[\w.-]+",
    "전화번호":    r"01\d-\d{3,4}-\d{4}",
    "URL":       r"https?://[^\s]+",
    "한글만":      r"[가-힣]+",
    "숫자(콤마포함)": r"\d{1,3}(?:,\d{3})*",
    "괄호 안 숫자":  r"\[(\d+)\]",
}

samples = {
    "이메일": "문의: test.user@example.co.kr",
    "전화번호": "010-1234-5678",
    "URL": "https://example.com/path?q=1",
    "한글만": "Hello 안녕하세요 123",
    "숫자(콤마포함)": "총 1,234,567원",
    "괄호 안 숫자": "근거[1]와 판례[23]",
}

for name, pattern in patterns.items():
    print(name, "->", re.findall(pattern, samples[name]))
```

3. `"[1], [2], [999]"`에서 1~10 범위의 숫자만 추출하는 정규식(lookahead 활용)을 만들어보세요.

<details>

```python
# 1번
text = "apple:3, banana:5, grape:12"
result = {name: int(num) for name, num in re.findall(r"(\w+):(\d+)", text)}

phone = "010-1234-5678"
masked = re.sub(r"(\d{3}-)\d{4}(-\d{4})", r"\1****\2", phone)

# 3번 (간단하게는 findall 후 필터링이 더 직관적입니다)
text = "[1], [2], [999]"
nums = [int(n) for n in re.findall(r"\[(\d+)\]", text)]
valid = [n for n in nums if 1 <= n <= 10]
print(valid)  # [1, 2]
```

## 요약 치트시트

```
.       임의의 문자 1개       \d      숫자              ^      문자열/줄 시작
*       0개 이상             \D      숫자 아님          $      문자열/줄 끝
+       1개 이상             \w      단어 문자          \b     단어 경계
?       0개 또는 1개          \W      단어 문자 아님      \B     단어 경계 아님
{n,m}   n~m개                \s      공백               |      OR
( )     캡처 그룹             \S      공백 아님          (?:)   비캡처 그룹
(?P<n>) 이름 붙은 그룹         (?=)    긍정 전방탐색       (?!)   부정 전방탐색
                            (?<=)   긍정 후방탐색       (?<!)  부정 후방탐색
```

### 보충

```python
import re

text = "Apple 10, Banana 20, Orange 30"

# 숫자를 찾는 패턴
pattern = r"\d+"

# 1. re.findall() 사용
results_findall = re.findall(pattern, text)
print("findall 결과:", results_findall)
# 출력: ['10', '20', '30'] (문자열 리스트 반환)

# 2. re.finditer() 사용
results_finditer = re.finditer(pattern, text)
print("finditer 결과:", results_finditer)
# 출력: <callable_iterator object at 0x...> (이터레이터 객체 반환)


# 이터레이터 내부의 Match 객체들을 순회하며 상세 정보 확인
for match in results_finditer:
print(f"매칭된 값: {match.group()}, 위치: {match.span()}")
# 출력:
# 매칭된 값: 10, 위치: (6, 8)
# 매칭된 값: 20, 위치: (17, 19)
# 매칭된 값: 30, 위치: (28, 30)

TEXT = re.compile(r"\d+")

for m in TEXT.findall(text):
print("findall2 결과:", m)
# 출력:
# findall2 결과: 10
# findall2 결과: 20
# findall2 결과: 30

for m in TEXT.finditer(text):
print("finditer2 결과:", m.group())
# 출력:
# finditer2 결과: 10
# finditer2 결과: 20
# finditer2 결과: 30
```
