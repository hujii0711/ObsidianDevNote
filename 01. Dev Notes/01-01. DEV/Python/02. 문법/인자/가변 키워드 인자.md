
`**args`(정확히는 `**kwargs` 형태)는 **"이름=값" 형태의 키워드 인자를 몇 개든 받아서 딕셔너리로 묶어주는** 문법이에요. 원래 코드를 먼저 분석하고, 쓰임새를 알 수 있는 예제로 확장해볼게요.

## 1. 원래 코드 분석

```python
def add_many(**args):
    print(args)

a = add_many()
print(a)
```

- `add_many()`를 **아무 인자 없이** 호출했기 때문에, 함수 내부의 `args`는 **빈 딕셔너리 `{}`**가 됩니다.
- `print(args)` → `{}` 출력
- 함수는 `print(args)`만 하고 **`return`이 없기** 때문에, 자동으로 `None`을 반환합니다.
- 그래서 `a = add_many()`의 결과 `a`는 `None`
- `print(a)` → `None` 출력

**실행 결과:**

```
{}
None
```

이 코드만 보면 `**args`가 왜 필요한지 감이 잘 안 오죠? 인자를 하나도 안 넘겼으니까요. 그래서 **실제로 값을 넘기는 예제**로 채워볼게요.

## 2. 쓰임새를 보여주는 예제로 확장

```python
def add_many(**args):
    print(args)
    result = 0
    for key, value in args.items():
        print(f"{key} = {value}")
        result += value
    return result

a = add_many(korean=90, english=85, math=100)
print(a)
```

### 실행 흐름

1. `add_many(korean=90, english=85, math=100)` 처럼 **`이름=값`** 형태로 인자를 넘기면,
2. 함수 내부의 `args`는 자동으로 딕셔너리로 묶입니다:
    
    ```python
    args = {'korean': 90, 'english': 85, 'math': 100}
    ```
    
3. `print(args)` → 딕셔너리 전체 출력
4. `for key, value in args.items():` → 딕셔너리를 `key`(과목명)와 `value`(점수)로 하나씩 꺼냄
5. `result += value` → 점수를 계속 더함 (`0 → 90 → 175 → 275`)
6. `return result` → 합계 `275` 반환

**출력 결과:**

```
{'korean': 90, 'english': 85, 'math': 100}
korean = 90
english = 85
math = 100
275
```

## 3. 왜 이런 방식이 유용한가요?

`**kwargs`의 진짜 장점은 **몇 개의 값이 들어올지 모를 때, 그리고 각 값에 "이름표(키)"를 붙이고 싶을 때** 빛을 발합니다.

```python
# 과목이 2개일 때도, 5개일 때도 함수 정의는 그대로!
add_many(korean=90, english=85)
add_many(korean=90, english=85, math=100, science=95, history=88)
```

만약 `**kwargs` 없이 함수를 만들었다면, 인자 개수가 다를 때마다 함수를 새로 정의하거나 매번 딕셔너리를 직접 만들어 넘겨야 했을 거예요.

## 4. `*args` vs `**kwargs` 비교

|구분|`*args`|`**kwargs`|
|---|---|---|
|호출 방식|`func(1, 2, 3)` (값만 나열)|`func(a=1, b=2)` (이름=값)|
|내부 자료형|튜플 `(1, 2, 3)`|딕셔너리 `{'a': 1, 'b': 2}`|
|값 접근|`for i in args`|`for key, value in kwargs.items()`|
|특징|순서만 있고 이름 없음|각 값에 이름(키)이 붙음|

## 5. 둘을 같이 쓰는 것도 가능해요

```python
def introduce(name, *hobbies, **info):
    print(f"이름: {name}")
    print(f"취미: {hobbies}")
    print(f"추가 정보: {info}")

introduce("철수", "독서", "게임", age=20, city="서울")
```

**출력:**

```
이름: 철수
취미: ('독서', '게임')
추가 정보: {'age': 20, 'city': '서울'}
```

- `name` : 일반 매개변수 (필수 값 하나)
- `*hobbies` : 이름 없이 나열된 값들 → 튜플
- `**info` : 이름=값으로 넘긴 값들 → 딕셔너리

정리하면, `**kwargs`는 **"이 값이 무엇을 의미하는지 이름표를 붙여서 여러 개 넘기고 싶을 때"** 쓰는 문법이라고 기억하시면 됩니다. 함수 호출 코드만 봐도 `korean=90`처럼 각 값이 뭘 의미하는지 바로 알 수 있다는 게 큰 장점이에요!
