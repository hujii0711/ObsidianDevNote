
## 1. `open()` - 파일 열기

파일을 읽거나 쓰기 위해 여는 함수입니다. 파일 입출력의 시작점이라고 보시면 됩니다.

```python
# 파일 쓰기 (write) - 없으면 새로 생성, 있으면 덮어씀
파일 = open("test.txt", "w", encoding="utf-8")
파일.write("안녕하세요!\n")
파일.write("파이썬 공부 중입니다.")
파일.close()  # 반드시 닫아줘야 함

# 파일 읽기 (read)
파일 = open("test.txt", "r", encoding="utf-8")
내용 = 파일.read()
print(내용)
파일.close()
```

```python
# 더 안전한 방법: with 구문 사용 (자동으로 close() 해줌)
with open("test.txt", "r", encoding="utf-8") as 파일:
    내용 = 파일.read()
    print(내용)
# with 블록을 벗어나면 자동으로 파일이 닫힘
```

> 💡 **모드(mode) 정리**
> 
> - `"r"` : 읽기 (read, 기본값)
> - `"w"` : 쓰기 (write, 기존 내용 덮어씀)
> - `"a"` : 추가 (append, 기존 내용 뒤에 이어씀)
> 
> 초보자에게는 `close()`를 잊어버리는 실수가 흔하니, **`with` 구문 사용을 강력 추천**합니다.

## 2. `ord()` - 문자를 숫자로 변환

문자 하나를 해당하는 유니코드 코드값(정수)으로 변환합니다. (`chr()`의 반대 개념)

```python
print(ord('A'))    # 65
print(ord('a'))    # 97
print(ord('가'))   # 44032

# 활용 예: 알파벳 순서 계산 (카이사르 암호 같은 것에 활용)
print(ord('C') - ord('A'))  # 2 (A부터 C까지 몇 칸 떨어졌는지)

# chr()과 짝을 이루는 개념
print(chr(ord('A') + 1))  # 'B' (A의 코드값 +1 → chr로 다시 문자화)
```

> 참고: `chr()`은 숫자 → 문자, `ord()`는 문자 → 숫자로 서로 정반대 기능입니다.

## 3. `pow()` - 거듭제곱 계산

거듭제곱(어떤 수를 몇 번 곱하는지)을 계산합니다. `**` 연산자와 같은 기능이에요.

```python
print(pow(2, 3))     # 8 (2의 3제곱, 2**3과 동일)
print(2 ** 3)         # 8 (동일한 결과)

print(pow(5, 2))     # 25 (5의 2제곱)

# pow()만의 특별한 기능: 세번째 인자로 나머지 연산까지 한번에!
print(pow(2, 10, 5))  # 4 → (2**10) % 5 와 같음, 훨씬 빠르게 계산됨
```

> 💡 일반적인 거듭제곱은 `**` 연산자를 더 많이 사용하지만, `pow(a, b, c)`처럼 세번째 인자를 활용한 **나머지 연산까지 포함된 거듭제곱**은 `pow()`에서만 가능하며 암호학 등에서 유용하게 쓰입니다.

## 4. `range()` - 연속된 숫자 범위 생성

일정 범위의 숫자들을 순서대로 생성합니다. `for` 반복문에서 정말 자주 함께 쓰이는 함수예요.

```python
# range(끝값) → 0부터 끝값-1까지
print(list(range(5)))        # [0, 1, 2, 3, 4]

# range(시작값, 끝값) → 시작값부터 끝값-1까지
print(list(range(2, 7)))     # [2, 3, 4, 5, 6]

# range(시작값, 끝값, 증가값)
print(list(range(0, 10, 2))) # [0, 2, 4, 6, 8] (2씩 증가)
print(list(range(10, 0, -1))) # [10, 9, 8, ..., 1] (거꾸로 감소)

# 활용 예: for문에서 반복 횟수 지정
for i in range(3):
    print(f"{i}번째 반복입니다.")
# 0번째 반복입니다.
# 1번째 반복입니다.
# 2번째 반복입니다.
```

> ⚠️ **주의**: `range(5)`는 0, 1, 2, 3, 4까지만 포함하고 5는 포함하지 않습니다. "끝값 - 1까지"라는 점을 꼭 기억하세요.

## 5. `round()` - 반올림

숫자를 지정한 소수점 자리까지 반올림합니다.

```python
print(round(3.14159))       # 3 (소수점 자리 생략시 정수로)
print(round(3.14159, 2))    # 3.14 (소수점 둘째자리까지)
print(round(3.14159, 4))    # 3.1416

print(round(2.5))           # 2 (주의! 파이썬은 "은행반올림" 방식 사용)
print(round(3.5))           # 4
```

> ⚠️ **주의: 파이썬의 반올림은 조금 특이합니다.** `round(2.5)`가 3이 아니라 2가 나오는 것을 보고 당황하실 수 있어요. 이는 파이썬이 **"은행가 반올림"(banker's rounding)** 방식을 사용하기 때문입니다. 정확히 .5인 경우, 가장 가까운 **짝수**로 반올림합니다.
> 
> ```python
> print(round(0.5))  # 0
> print(round(1.5))  # 2
> print(round(2.5))  # 2
> print(round(3.5))  # 4
> ```
> 
> 일반적인 반올림 결과가 필요하다면 별도의 로직이 필요할 수 있으니 유의하세요.

---

이번 5개 중에서 **`open()`은 with 구문과 함께 사용하는 습관을 꼭 들이시고**, `range()`는 반복문의 핵심이니 확실히 익혀두세요. `round()`의 반올림 방식은 실무에서 종종 놀라는 부분이니 꼭 기억해두시길 바랍니다!
