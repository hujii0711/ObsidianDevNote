
## 1. `id()` - 객체의 고유 식별값 확인

파이썬에서 모든 객체(변수, 값 등)는 메모리 상에 저장되는데, `id()`는 그 객체의 고유한 식별 번호(메모리 주소 기반)를 반환합니다.

```python
a = 10
print(id(a))  # 예: 140712834567232 (실행할 때마다 다를 수 있음)

# 같은 값을 가진 두 변수가 같은 객체인지 확인할 때 유용
b = 10
print(id(a) == id(b))  # True (작은 정수는 파이썬이 재사용함)

# 리스트는 다름 (가변 객체라서 각각 새로 생성됨)
list1 = [1, 2, 3]
list2 = [1, 2, 3]
print(id(list1) == id(list2))  # False (값은 같지만 서로 다른 객체)
print(list1 == list2)  # True (값 비교는 이걸로)
```

> 💡 `id()`는 실무에서 자주 쓰이진 않지만, "왜 이 두 변수가 같은데 다르게 동작하지?" 같은 상황에서 객체의 정체성을 파악하는 데 도움이 됩니다. `is` 연산자가 내부적으로 이 `id()` 값을 비교하는 것이라고 생각하시면 됩니다.

## 2. `input()` - 사용자로부터 입력받기

키보드로 사용자의 입력을 받아서 **문자열(string)** 형태로 반환합니다.

```python
이름 = input("이름을 입력하세요: ")
print(f"안녕하세요, {이름}님!")

# 입력 실행 예시
# 이름을 입력하세요: 철수
# 안녕하세요, 철수님!
```

```python
# 주의: input()의 결과는 항상 문자열!
나이 = input("나이를 입력하세요: ")
print(type(나이))  # <class 'str'> (숫자를 입력해도 문자열임)

# 숫자로 계산하려면 반드시 변환 필요
나이 = int(input("나이를 입력하세요: "))
print(나이 + 1)  # 정상적으로 계산됨
```

## 3. `int()` - 정수로 변환

문자열이나 실수(float)를 정수(integer)로 변환합니다.

```python
print(int("10"))     # 10
print(int(3.9))       # 3 (소수점 이하는 버림, 반올림 아님!)
print(int("  7  "))   # 7 (공백은 자동으로 제거됨)

# 변환 불가능한 경우 에러 발생
print(int("hello"))   # ValueError 발생!
print(int("3.5"))     # ValueError! (소수점 있는 문자열은 바로 변환 안됨)

# 이런 경우엔 float으로 먼저 변환 후 int로
print(int(float("3.5")))  # 3

# 활용 예: input()과 함께 자주 사용
나이 = int(input("나이: "))
print(나이 * 2)
```

> ⚠️ `int(3.9)`는 반올림이 아니라 **버림**입니다. 3.9든 3.1이든 소수점 이하를 그냥 잘라내서 3이 됩니다.

## 4. `isinstance()` - 자료형(타입) 확인

어떤 객체가 특정 타입(자료형)인지 확인해서 `True`/`False`로 알려줍니다.

```python
print(isinstance(10, int))        # True
print(isinstance("hello", str))   # True
print(isinstance(3.14, int))      # False (실수는 int가 아님)

# 여러 타입 중 하나인지 한번에 확인 (튜플로 전달)
print(isinstance(10, (int, float)))    # True
print(isinstance("hi", (int, float)))  # False

# 활용 예: 함수 안에서 입력값 타입 검증
def 더하기(a, b):
    if not isinstance(a, (int, float)) or not isinstance(b, (int, float)):
        return "숫자만 입력해주세요!"
    return a + b

print(더하기(3, 5))       # 8
print(더하기("3", 5))     # 숫자만 입력해주세요!
```

> 💡 `type(x) == int`로도 타입 확인이 가능하지만, `isinstance()`가 더 권장됩니다. 상속 관계(부모-자식 클래스)도 제대로 인식해주기 때문이에요.

## 5. `len()` - 길이(개수) 구하기

문자열, 리스트, 튜플, 딕셔너리 등의 **길이(요소 개수)**를 반환합니다. 정말 자주 쓰이는 필수 함수예요.

```python
print(len("hello"))          # 5 (문자 개수)
print(len([1, 2, 3, 4]))     # 4 (리스트 요소 개수)
print(len((1, 2)))           # 2 (튜플 요소 개수)
print(len({"a": 1, "b": 2})) # 2 (딕셔너리는 key 개수)

# 활용 예: 반복문과 함께 자주 사용
과일 = ['사과', '바나나', '체리']
for i in range(len(과일)):
    print(과일[i])

# 활용 예: 빈 리스트인지 확인
장바구니 = []
if len(장바구니) == 0:
    print("장바구니가 비어있습니다.")
```

---

이번 5개 중에서 **`input()`, `int()`, `len()`은 거의 모든 파이썬 프로그램에서 쓰이는 필수 함수**이니 꼭 익숙해지시고, `input()`의 결과가 항상 문자열이라는 점을 특히 기억해두세요!
