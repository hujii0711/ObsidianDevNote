
## 1. `list()` - 리스트로 변환

다른 자료형(튜플, 문자열, range 등)을 리스트로 변환합니다.

```python
print(list((1, 2, 3)))       # [1, 2, 3] (튜플 → 리스트)
print(list("hello"))          # ['h', 'e', 'l', 'l', 'o'] (문자열 → 문자 리스트)
print(list(range(5)))         # [0, 1, 2, 3, 4] (range → 리스트)

# 빈 리스트 만들기
빈리스트 = list()
print(빈리스트)  # []
# print([]) 와 동일

# 활용 예: filter, map의 결과를 눈으로 확인할 때
숫자들 = filter(lambda x: x > 5, [1, 5, 8, 10])
print(list(숫자들))  # [8, 10]

# 활용 예: 딕셔너리의 key만 리스트로
정보 = {"이름": "철수", "나이": 20}
print(list(정보))  # ['이름', '나이']
```

## 2. `map()` - 모든 요소에 함수 적용

리스트 등의 **모든 요소에 동일한 함수를 적용**해서 새로운 결과를 만들어줍니다.

```python
숫자들 = [1, 2, 3, 4, 5]

# 각 숫자를 제곱하기
def 제곱(x):
    return x ** 2

결과 = map(제곱, 숫자들)
print(list(결과))  # [1, 4, 9, 16, 25]

# lambda(익명함수)와 함께 더 간결하게
결과2 = map(lambda x: x ** 2, 숫자들)
print(list(결과2))  # [1, 4, 9, 16, 25]

# 활용 예: 문자열로 된 숫자 리스트를 정수로 한번에 변환
문자열숫자 = ["1", "2", "3"]
정수숫자 = list(map(int, 문자열숫자))
print(정수숫자)  # [1, 2, 3]
```

> 💡 `map()`도 `filter()`처럼 결과가 바로 리스트로 안 보이고 `map` 객체로 나오니, 확인하려면 `list()`로 감싸주세요.

## 3. `max()` - 최댓값 구하기

여러 값 중에서 **가장 큰 값**을 반환합니다.

```python
print(max(3, 7, 2))          # 7 (여러 인자 중 최댓값)
print(max([5, 1, 9, 3]))     # 9 (리스트 안에서 최댓값)
print(max("apple", "banana")) # 'banana' (문자열은 사전순 비교)

# 활용 예: 가장 점수가 높은 학생 찾기
점수 = {"철수": 85, "영희": 92, "민수": 78}
print(max(점수, key=점수.get))  # '영희' (key로 비교 기준 지정)

# 활용 예: 문자열 길이 기준으로 가장 긴 단어 찾기
단어들 = ["cat", "elephant", "dog"]
print(max(단어들, key=len))  # 'elephant'
```

## 4. `min()` - 최솟값 구하기

`max()`와 반대로, 여러 값 중에서 **가장 작은 값**을 반환합니다. 사용법은 완전히 동일해요.

```python
print(min(3, 7, 2))          # 2
print(min([5, 1, 9, 3]))     # 1
print(min("apple", "banana")) # 'apple' (사전순으로 더 앞선 것)

# 활용 예: 가장 점수가 낮은 학생 찾기
점수 = {"철수": 85, "영희": 92, "민수": 78}
print(min(점수, key=점수.get))  # '민수'

# 활용 예: 가장 짧은 단어 찾기
단어들 = ["cat", "elephant", "dog"]
print(min(단어들, key=len))  # 'cat'
```

> 💡 **`max`/`min` 공통 팁**: `key=` 옵션을 사용하면 "무엇을 기준으로 비교할지"를 직접 지정할 수 있어서 매우 유용합니다.

## 5. `oct()` - 숫자를 8진수 문자열로 변환

정수를 8진수(octal) 형태의 문자열로 바꿔줍니다.

```python
print(oct(8))     # '0o10'
print(oct(64))    # '0o100'
print(oct(7))     # '0o7'

# 앞의 '0o'는 "이건 8진수야"라는 표시
숫자 = 100
print(oct(숫자))  # '0o144'
```

> 참고로 8진수 문자열을 다시 정수로 바꾸려면 `int("144", 8)`처럼 `int()`에 진법 8을 지정하면 됩니다. → `100`
> 
> `oct()`는 실무에서 자주 쓰이는 함수는 아니지만, 유닉스/리눅스 **파일 권한 표기**(예: `chmod 755`)를 다룰 때 8진수 개념이 등장하니 알아두면 좋습니다.

---

이번 5개 중에서 **`map()`, `max()`, `min()`은 실무에서 데이터를 다룰 때 매우 자주 쓰이니** 꼭 익혀두시고, 특히 `max()`/`min()`의 `key=` 옵션은 나중에 정렬 함수(`sorted()`)에서도 똑같이 활용되니 함께 기억해두시면 좋습니다!
