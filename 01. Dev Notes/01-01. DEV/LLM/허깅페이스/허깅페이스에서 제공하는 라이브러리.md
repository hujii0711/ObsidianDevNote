
허깅페이스(Hugging Face)는 단순히 모델을 공유하는 플랫폼을 넘어, 인공지능 개발·학습·배포 전 과정을 아우르는 강력한 오픈소스 파이썬 라이브러리 생태계를 제공합니다.

개발자들이 가장 많이 사용하는 핵심 라이브러리들을 용도별로 정리해 드립니다.

### 1. 모델 활용 및 핵심 라이브러리

- **`transformers`** (대표 라이브러리)
    - LLM(텍스트), 비전, 오디오, 멀티모달 등 수만 개의 사전 학습된 모델을 몇 줄의 파이썬 코드로 불러와 사용할 수 있게 해주는 사실상의 표준(De facto standard) 라이브러리입니다.

- **`datasets`**
    - 허깅페이스 허브에 있는 방대한 데이터셋을 단 몇 줄로 다운로드, 스트리밍, 전처리 및 관리할 수 있게 돕는 라이브러리입니다.
    
- **`tokenizers`**
    - Rust 기반으로 작성되어 대용량 텍스트를 엄청난 속도로 토큰화(Tokenization)해 주는 고성능 라이브러리입니다.

### 2. 학습 및 파인튜닝(Fine-tuning) 라이브러리

- **`peft` (Parameter-Efficient Fine-Tuning)**
    - LoRA 등의 기법을 이용해 전체 모델을 수정하지 않고 적은 자원(VRAM)으로 대형 언어 모델을 효율적으로 파인튜닝할 수 있게 해줍니다.

- **`trl` (Transformer Reinforcement Learning)**
    - 강화학습(PPO, DPO 등)을 활용해 LLM을 정렬(Alignment)하고 학습시키는 데 특화된 라이브러리입니다.

- **`accelerate`**
    - PyTorch 코드를 수정할 거의 없이 단일 GPU, 멀티 GPU, 분산 환경(TPU 등)에서 손쉽게 코드를 실행할 수 있도록 지원하는 라이브러리입니다.

### 3. 멀티모달 및 최적화 라이브러리

- **`diffusers`**
    - Stable Diffusion 등을 포함하여 이미지 생성, 비디오 생성, 오디오 확산 모델(Diffusion Models)을 다루기 위한 모듈식 툴박스입니다.

- **`safetensors`**
    - 기존 파이토치의 `.bin` 형식 대신, 보안성과 로딩 속도가 훨씬 뛰어난 안전한 가중치(Weights) 파일 저장·공유 포맷입니다.

- **`optimum`**

    - ONNX, TensorRT 등 하드웨어 가속 환경에 맞춰 모델을 최적화하고 양자화(Quantization)할 수 있는 도구 모음입니다.

### 4. 배포 및 에이전트 라이브러리

- **`Text Generation Inference (TGI)`**
    - 프로덕션 환경에서 LLM을 대규모로 고속 서빙(Inference)하기 위해 최적화된 백엔드 툴킷입니다.

- **`transformers.js`**
    - 파이썬 서버 없이 웹 브라우저(JavaScript) 환경 안에서 직접 최신 머신러닝 모델을 구동할 수 있게 해줍니다.

- **`smolagents`**
    - 파이썬 환경에서 가볍고 직관적인 방식으로 AI 에이전트(Autonomous Agents) 루프를 구축할 수 있도록 지원하는 최신 라이브러리입니다.
