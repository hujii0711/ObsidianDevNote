
M4 Pro 48GB면 로컬 Qwen 에이전트 돌리기에 꽤 좋은 스펙이에요. 정리해드릴게요.

## 하드웨어 특성부터

M4 Pro는 273GB/s 메모리 대역폭을 갖고 있고, 48GB 유니파이드 메모리는 M4 Pro 구성에서 선택 가능한 옵션 중 하나입니다. 48GB M4 Pro는 로컬 LLM 용도로 "스위트 스폿(sweet spot)"으로 꼽히는 사양입니다.

실사용 후기로는, 20B~30B 정도의 모델은 M4 48GB 로컬 환경에서 충분히 소화 가능하며, 그 이상으로 모델 크기를 키우기는 어렵다는 게 중론입니다.

## 추천 모델**핵심 추천: Qwen3-30B-A3B (MLX 4bit)**

가장 균형 잡힌 선택이에요. 30B급 모델 기준 초당 약 35~45토큰의 속도가 나와서 실사용에 무리가 없습니다. MoE(Mixture-of-Experts) 구조라 전체 파라미터는 30B지만 토큰당 실제 활성화되는 파라미터는 훨씬 적어서(A3B = Active 3B), 48GB 메모리에서 여유 있게 돌아가면서도 속도가 빠른 게 장점입니다.

**용도별 가이드**

|상황|추천 모델|
|---|---|
|빠른 반응이 중요한 일반 채팅/간단한 도구 호출|Qwen3-14B 또는 8B|
|**Hermes 에이전트 메인 모델 (범용)**|**Qwen3-30B-A3B** ← 이걸로 시작 추천|
|코딩/파일 조작 위주 에이전트 작업|Qwen3-Coder-30B-A3B|
|최대한 크게 (여유 있다면)|Qwen3-32B (dense) — 30B-A3B보다 느리지만 추론 품질 약간 우위|

**설정 팁**

1. **양자화는 MLX 4bit로**: Mac에서 LLM을 돌리신다면 MLX 프레임워크 기반 모델이 GGUF보다 더 빠른 추론을 냅니다. LM Studio에서 검색할 때 모델명에 "MLX"가 붙은 버전을 고르세요.
2. **72B급, Qwen3-Max급은 피하세요**: M4 48GB 사양에서 모델 크기를 더 키우기는 어렵다는 게 중론이라, 32B가 사실상 상한선입니다.
3. **컨텍스트 길이**: 앞서 안내드린 대로 Hermes는 도구 스키마 때문에 오버헤드가 크니, Context Length는 32K 이상으로 설정하세요. 30B-A3B 모델 + 32K 컨텍스트면 48GB 안에서 충분히 여유가 있습니다.

**결론**: `Qwen3-30B-A3B-MLX-4bit`를 LM Studio에서 받아 로드하고, Hermes의 Custom Endpoint(`http://localhost:1234/v1`)로 연결하시면 될 것 같습니다. 코딩 작업 비중이 높으시면 `Qwen3-Coder-30B-A3B`로 바로 가셔도 좋고요.
