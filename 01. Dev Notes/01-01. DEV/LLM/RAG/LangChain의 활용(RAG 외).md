
LangChain은 문서 기반 질의응답(RAG) 외에도 LLM을 활용한 다양한 애플리케이션 아키텍처 구축에 광범위하게 사용됩니다.

**1. AI 에이전트 및 자율 워크플로우 (Agents)**
- 도구(tool)를 스스로 선택해 사용하는 자율 에이전트 구축
- LangGraph와 결합해 복잡한 멀티스텝 워크플로우, 상태 기반(state machine) 에이전트 구현
- 웹 검색, 코드 실행, API 호출 등을 스스로 판단해 수행하는 시스템

**2. 워크플로우 자동화 / 오케스트레이션**
- 여러 LLM 호출과 외부 API를 체이닝해 업무 자동화 파이프라인 구축 (예: 고객 문의 분류 → 라우팅 → 응답)
- SQL 데이터베이스, CRM, 사내 시스템과 연동한 자동화

**3. 대화형 챗봇 / 메모리 관리**
- 단순 RAG를 넘어 대화 이력을 기억하고 컨텍스트를 유지하는 챗봇
- 단기/장기 메모리 모듈을 활용한 개인화 어시스턴트

**4. 정형 데이터 및 SQL 쿼리 연동 (Querying Tabular Data)**
- 자연어로 된 질문을 받아 내부적으로 SQL 쿼리나 판다스(Pandas) 코드로 변환한 뒤, 관계형 데이터베이스나 CSV/Excel 파일에서 직접 데이터를 조회하고 분석 결과를 사용자 친화적인 언어로 요약해 줍니다.
 
**5. 외부 API 및 시스템 연동 (Interacting with APIs)**
- LLM이 외부 서비스(REST API, 클라우드 서비스, 이메일 전송 도구 등)와 통신할 수 있도록 인터페이스를 연결합니다. 모델이 특정 상황에서 어떤 API를 어떤 파라미터로 호출해야 하는지 구조화된 형태로 제어할 수 있습니다.

**6. 데이터 추출 및 구조화**
- Structured Output 기능으로 스키마에 맞는 데이터 파싱
- 비정형 텍스트(이력서, 영수증, 뉴스 기사 등)에서 사용자가 원하는 특정 스키마나 JSON 포맷의 데이터를 정확하게 추출해내는 태스크에 활용됩니다. Pydantic 등과 연동하여 타입 안정성이 보장된 데이터 파싱을 구현할 수 있습니다.

**7. 코드 이해 및 생성 (Code Understanding & Evaluation)**
- 대규모 코드베이스를 로드하고 파싱하여 코드 분석, 리팩토링 제안, 자동 문서화 및 단위 테스트 생성 등의 개발 자동화 도구 파이프라인에 적용됩니다. 또한 LLM 기반 애플리케이션의 성능을 평가(Evaluation)하는 파이프라인 구축에도 쓰입니다.
