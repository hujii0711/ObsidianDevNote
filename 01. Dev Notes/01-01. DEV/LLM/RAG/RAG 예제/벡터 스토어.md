### 디스크 저장

`persist_directory`를 지정하지 않으면 Chroma는 **메모리 모드**로 동작하기 때문에, 파이썬 프로세스(노트북 커널)가 종료되면 벡터 데이터도 함께 사라집니다. 다음에 실행할 때 임베딩을 다시 만들어야 하므로 OpenAI 비용도 다시 듭니다.

디스크에 저장하려면 `persist_directory`를 지정하면 됩니다.

```python
import os
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_chroma import Chroma          # pip install langchain-chroma

os.environ["OPENAI_API_KEY"] = "YOUR_OPENAI_API_KEY"

openai_embedding = OpenAIEmbeddings(model="text-embedding-3-small")

loader = PyPDFLoader(r"../data/대한민국헌법(헌법)(제00010호)(19880225).pdf")
pages = loader.load()

text_splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=0)
docs = text_splitter.split_documents(pages)

# 디스크에 저장
db = Chroma.from_documents(
    documents=docs,
    embedding=openai_embedding,
    persist_directory="./chroma_db",     # 이 폴더에 저장됨
    collection_name="constitution",
)
```

**다음에 실행할 때는 임베딩을 다시 만들지 말고 불러오기만 하면 됩니다.**

```python
db = Chroma(
    persist_directory="./chroma_db",
    embedding_function=openai_embedding,   # 저장할 때와 같은 임베딩 모델이어야 함
    collection_name="constitution",
)

print(db._collection.count())              # 저장된 청크 수 확인
results = db.similarity_search("대통령의 임기는?", k=3)
```

참고할 점이 몇 가지 있습니다.

- **`db.persist()`는 필요 없습니다.** chromadb 0.4 이후로는 `persist_directory`를 지정하면 자동으로 저장되며, `persist()` 메서드는 deprecated 되었습니다.
- **`from_documents`를 반복 실행하면 같은 문서가 중복으로 쌓입니다.** 노트북에서 셀을 여러 번 실행했다면 `count()`로 확인해 보세요. 이를 막으려면 "폴더가 있으면 불러오고, 없으면 새로 생성"하는 분기를 두거나, `ids=`를 직접 지정해 같은 ID는 덮어쓰도록 하면 됩니다.
- import 경로를 최신 방식으로 바꾸었습니다. `langchain.vectorstores.Chroma`는 `langchain_chroma.Chroma`로, `langchain.document_loaders`는 `langchain_community.document_loaders`로 바뀌었습니다.
- 원래 코드는 `load_and_split()`으로 한 번 쪼갠 뒤 다시 `split_documents()`를 호출해서 분할이 두 번 일어납니다. `load()` 후에 한 번만 분할하는 편이 의도에 맞습니다.
- API 키를 코드에 직접 쓰기보다는 `.env` 파일과 `python-dotenv`로 불러오는 것이 안전합니다.
