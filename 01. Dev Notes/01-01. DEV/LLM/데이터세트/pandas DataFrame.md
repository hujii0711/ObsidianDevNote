
`DataFrame`은 파이썬 `pandas` 라이브러리의 핵심 자료구조로, **행(row)과 열(column)로 구성된 2차원 표 형태의 데이터**를 다루는 데 사용됩니다. 엑셀 시트나 SQL 테이블과 비슷한 구조라고 생각하면 이해하기 쉽습니다.

## 기본 개념

- **행(row)**: 하나의 데이터 레코드
- **열(column)**: 특정 속성(변수)을 나타내며, 열마다 서로 다른 데이터 타입(정수, 실수, 문자열 등) 가능
- **인덱스(index)**: 각 행을 식별하는 라벨 (기본값은 0부터 시작하는 정수)

## 생성 예시

```python
import pandas as pd

data = {
    "이름": ["철수", "영희", "민수"],
    "나이": [25, 30, 28],
    "도시": ["서울", "부산", "대구"]
}

df = pd.DataFrame(data)
print(df)
```

출력:

```
   이름  나이  도시
0  철수  25  서울
1  영희  30  부산
2  민수  28  대구
```

## 주요 속성 및 메서드

|기능|설명|
|---|---|
|`df.head()`|처음 몇 개의 행 확인|
|`df.shape`|(행 개수, 열 개수) 반환|
|`df.columns`|열 이름 목록|
|`df.dtypes`|각 열의 데이터 타입|
|`df.describe()`|수치형 데이터의 통계 요약|
|`df.loc[]` / `df.iloc[]`|라벨/위치 기반 데이터 선택|
|`df.isnull()`|결측치 확인|
|`df.groupby()`|그룹별 집계 연산|
|`df.merge()`|다른 DataFrame과 병합(SQL join과 유사)|

## 자주 하는 작업

```python
# 열 선택
df["나이"]

# 조건 필터링
df[df["나이"] > 26]

# 새 열 추가
df["성인여부"] = df["나이"] >= 20

# CSV로 저장/불러오기
df.to_csv("data.csv", index=False)
pd.read_csv("data.csv")
```

## 왜 유용한가

- 대용량 데이터를 효율적으로 처리 (내부적으로 NumPy 기반)
- 결측치 처리, 필터링, 정렬, 그룹화, 병합 등 데이터 분석 기능 대부분 내장
- CSV, Excel, SQL, JSON 등 다양한 형식과 쉽게 연동
