### 1. torch
torch 모듈은 Python에서 **PyTorch**라는 딥러닝 프레임워크의 핵심 라이브러리입니다. PyTorch는 인공 신경망을 구축하고 학습시키는 데 필요한 다양한 도구를 제공하며, 특히 다음과 같은 역할을 합니다:

1. **텐서(Tensor) 연산**:  
   PyTorch의 핵심 데이터 구조인 텐서를 사용하여 수학적 연산을 수행합니다. 텐서는 다차원 배열로, NumPy의 배열과 유사하지만 GPU를 활용한 고속 연산이 가능합니다.

2. **자동 미분(Autograd)**:  
   모델을 학습시키기 위해서는 손실 함수의 그래디언트를 계산하고 역전파(backpropagation)를 통해 가중치를 업데이트해야 합니다. `torch`는 자동 미분 기능을 제공하여, 복잡한 수학적 연산의 그래디언트를 자동으로 계산합니다.

3. **신경망 구축 도구**:  
   `torch.nn` 모듈은 딥러닝 모델을 구성하는 다양한 계층(layer)과 함수(function)를 제공합니다. 이 모듈을 사용하여 신경망을 쉽게 설계할 수 있습니다.

4. **GPU 가속**:  
   PyTorch는 GPU를 활용하여 대규모 데이터에 대한 연산을 빠르게 수행할 수 있도록 지원합니다. CUDA를 통해 GPU에서 텐서 연산을 처리하여 연산 속도를 크게 높일 수 있습니다.

5. **모델 학습 및 평가**:  
   PyTorch는 모델을 훈련하고 평가하는 과정에서 필요한 함수와 클래스를 제공합니다. `torch.optim` 모듈을 사용하여 다양한 최적화 알고리즘(예: SGD, Adam 등)을 적용할 수 있습니다.

6. **커스텀 모델 정의**:  
   사용자는 기본 제공 계층 외에도, `torch.autograd`를 이용해 커스텀 레이어와 모델을 정의하고 미분할 수 있습니다.

즉, PyTorch는 머신러닝과 딥러닝 모델을 설계하고 학습시키는 데 필요한 강력한 도구들을 제공합니다.

### 2. pandas
pandas 모듈은 Python에서 **데이터 분석**과 **데이터 조작**을 위한 강력한 라이브러리입니다. 특히, 구조화된 데이터를 효율적으로 다룰 수 있도록 다양한 도구를 제공하며, 다음과 같은 역할을 합니다:

1. **데이터 구조 제공**:
   - `pandas`는 두 가지 주요 데이터 구조인 **Series**와 **DataFrame**을 제공합니다.
     - **Series**: 1차원 데이터 구조로, 라벨이 지정된 데이터를 다룰 수 있습니다. 예를 들어, 인덱스를 지정하여 데이터를 쉽게 조회하고 관리할 수 있습니다.
     - **DataFrame**: 2차원 테이블 구조로, 행과 열로 구성된 데이터를 다룹니다. 엑셀 시트나 SQL 테이블과 유사한 구조로, 여러 유형의 데이터를 혼합하여 사용할 수 있습니다.

2. **데이터 입출력**:
   - `pandas`는 다양한 파일 형식으로부터 데이터를 쉽게 불러오고 저장할 수 있습니다. 예를 들어:
     - CSV, 엑셀 파일, SQL 데이터베이스, JSON, HTML 등에서 데이터를 읽어올 수 있습니다.
     - 데이터를 다시 원하는 형식으로 저장할 수 있습니다.

3. **데이터 조작 및 변환**:
   - 데이터 프레임에서 데이터를 필터링, 정렬, 병합(merge), 그룹화(groupby)하는 등의 다양한 조작을 간단히 할 수 있습니다.
   - 결측치 처리, 중복 데이터 제거, 열과 행의 추가 및 삭제, 열 이름 변경 등 다양한 변환 작업을 지원합니다.

4. **데이터 탐색 및 분석**:
   - `pandas`는 데이터를 요약하고 통계적 정보를 제공하는 함수들을 포함하고 있습니다. 평균, 중앙값, 분산 등의 기본적인 통계 함수뿐만 아니라, 각 열의 데이터 타입이나 고유 값의 개수 등도 쉽게 확인할 수 있습니다.
   - 그룹화(groupby) 및 피벗 테이블(pivot table)을 사용하여 복잡한 데이터 집계를 수행할 수 있습니다.

5. **시계열 데이터 처리**:
   - `pandas`는 시계열 데이터 처리에 강력한 도구를 제공합니다. 시간 인덱스를 사용하여 시계열 데이터를 처리하고, 리샘플링(resampling), 시계열 데이터 이동 등 다양한 기능을 지원합니다.

6. **데이터 시각화**:
   - `pandas`는 `matplotlib` 같은 시각화 라이브러리와 쉽게 통합되어 데이터프레임에서 바로 그래프를 생성할 수 있습니다. 이를 통해 데이터를 시각적으로 분석하고 인사이트를 얻을 수 있습니다.

결론적으로, `pandas`는 대규모 데이터를 효율적으로 처리하고 분석하는 데 필요한 도구들을 제공하며, 특히 데이터 분석 작업을 단순화하고 속도를 높이는 데 매우 유용한 라이브러리입니다.

### Pandas 활용 시점
로컬 LLM 파인튜닝 데이터셋 구축 과정에서 판다스(Pandas)는 원시 데이터를 수집하고 LLM 학습용 포맷으로 가공·정제하는 **<font color="#ff0000">데이터 전처리</font>**(Data Wrangling) 단계 전반에서 핵심적으로 활용됩니다.

<font color="#ff0000">1. 대용량 원시 데이터 수집 및 로드</font>
- **활용 시점:** CSV, Excel, JSON, 로그 파일(텍스트), SQL 데이터베이스 등 다양한 소스로부터 대량의 원시 데이터를 한 번에 메모리로 불러올 때 사용합니다.
 
- **예시:** 사내 이슈 트래커 로그나 기존 Q&A 데이터베이스 파일을 `pd.read_csv()`나 `pd.read_json()`으로 로드하여 데이터프레임 구조로 변환합니다.

<font color="#ff0000">2. 데이터 정제 및 필터링 (Data Cleaning)</font>
- **활용 시점:** 수집한 데이터 중 결측치(Null), 중복 데이터, 쓸모없는 특수문자나 HTML 태그가 섞여 있는 노이즈를 제거할 때 사용합니다.

- **예시:** `.dropna()`, `.drop_duplicates()`, `.str.replace()` 등의 메서드를 활용해 학습에 방해가 되는 불량 데이터를 일괄적으로 정제합니다.

<font color="#ff0000">3. LLM 데이터셋 포맷 구조화 및 변환 (Alpaca / ShareGPT)</font>
- **활용 시점:** 정제된 데이터를 Alpaca 포맷(`instruction`, `input`, `output`)이나 ShareGPT 포맷(`conversations`) 같은 **JSON 스키마 형태로 매핑**할 때 사용합니다.

- **예시:** 기존 데이터프레임의 컬럼(`question`, `answer`)을 대화형 딕셔너리 구조로 변환하기 위해 `.apply()` 함수나 리스트 컴프리헨션을 결합하여 최종 JSON 데이터셋 객체를 조립합니다.

<font color="#ff0000">4. 데이터 분할 및 통계 검수 (Train / Validation Split)</font>
- **활용 시점:** 전체 데이터셋을 셔플(Shuffle)하여 학습용과 검증용으로 나누거나, 토큰 길이 분포 등을 통계적으로 확인할 때 사용합니다.

- **예시:** `.sample(frac=1)`로 전체 행을 무작위로 섞은 뒤, 전체 데이터의 90%를 `train_df`, 나머지 10%를 `val_df`로 슬라이싱하여 각각 최종 파일로 저장합니다.

#### DataFrame

DataFrame(데이터프레임)은 판다스(Pandas)를 대표하는 **핵심 2차원 자료구조**입니다.
행(Row)과 열(Column)이 있는 엑셀 스프레드시트나 SQL 테이블 형태의 데이터를 파이썬 안에서 다룰 수 있도록 만든 객체입니다.

**1. 판다스에서 DataFrame의 역할**
- **표 형태의 데이터 처리:** 텍스트, 숫자, 날짜 등 다양한 타입의 데이터를 행과 열 구조로 깔끔하게 정리합니다.

- **데이터 조작 및 정제:** 결측치 제거, 열 추가·삭제, 조건 검색, 그룹화(`groupby`) 등 데이터 전처리에 필요한 모든 강력한 기능을 이 DataFrame 객체를 통해 수행합니다.

**2. 간단한 생성 및 활용 예시**

```python
import pandas as pd

# 딕셔너리 형태로 데이터를 입력해 DataFrame 객체 생성
data = {
    "instruction": ["한국의 수도는 어디인가요?", "HTML의 뜻은 무엇인가요?"],
    "output": ["서울입니다.", "HyperText Markup Language입니다."]
}

df = pd.DataFrame(data)

# 출력 결과 (행/열 구조의 표 형태)
print(df)
```

### 3. Numpy
NumPy는 파이썬에서 과학 계산을 위한 핵심 라이브러리로, 주로 다차원 배열 객체와 다양한 수학 함수를 제공합니다. NumPy의 주요 역할과 기능은 다음과 같습니다:

1. **다차원 배열 객체(ndarray)**:
   - NumPy의 핵심은 `ndarray`라는 다차원 배열 객체입니다. 이는 효율적인 메모리 사용과 빠른 연산을 가능하게 합니다.
   - 배열은 다양한 데이터 타입을 지원하며, 수학적 연산을 쉽게 수행할 수 있도록 설계되었습니다.

2. **수학 함수 및 연산**:
   - NumPy는 배열 간의 기본적인 산술 연산뿐만 아니라 선형대수, 통계, 푸리에 변환 등의 고급 수학 함수를 제공합니다.
   - 배열 간의 요소별 연산 및 행렬 연산을 효율적으로 수행할 수 있습니다.

3. **브로드캐스팅**:
   - 서로 다른 크기의 배열 간의 연산을 가능하게 하는 브로드캐스팅 기능을 제공합니다. 이는 배열의 크기를 자동으로 맞추어 연산을 수행할 수 있도록 합니다.

4. **배열 조작**:
   - 배열의 크기 변경, 형태 변환, 전치, 축 추가 및 제거 등 다양한 배열 조작 기능을 지원합니다.

5. **파일 I/O**:
   - 바이너리 및 텍스트 형식으로 배열 데이터를 저장하고 로드할 수 있는 기능을 제공합니다.

6. **통합 및 호환성**:
   - NumPy는 다른 과학 계산 라이브러리(예: SciPy, pandas, Matplotlib 등)와 잘 통합되며, 이러한 라이브러리들의 기초를 형성합니다.

7. **고성능**:
   - NumPy는 C로 구현되어 있어, 파이썬의 기본 리스트보다 훨씬 빠른 속도로 배열 연산을 수행할 수 있습니다.

이러한 기능들 덕분에 NumPy는 데이터 분석, 머신러닝, 통계, 수치 해석 등 다양한 분야에서 널리 사용됩니다. NumPy의 효율적이고 강력한 배열 처리 기능은 많은 데이터 과학 작업의 기반이 됩니다.

### Pandas 활용 시점

데이터 전처리 및 LLM 파인튜닝 과정에서 넘파이(NumPy)는 파이썬 기본 리스트가 처리하기 버거운 **대규모 수치 연산, 고차원 배열 가공, 그리고 딥러닝 프레임워크와의 데이터 인터페이스** 단계에서 가장 유용하게 활용됩니다.

<font color="#ff0000">1. 대규모 데이터의 고속 벡터화 연산 및 변환</font>
- **활용 시점:** 수만 개 이상의 텍스트 데이터 길이를 통계적으로 분석하거나, 대량의 행렬 데이터를 루프(Loop) 없이 일괄 처리할 때 사용합니다.
 
- **예시:** 데이터셋에 포함된 모든 프레임워크 텍스트의 토큰 길이를 구한 뒤, 평균·분포·백분위수(`np.mean()`, `np.percentile()`)를 밀리초 단위로 빠르게 계산할 때 활용합니다.

<font color="#ff0000">2. 딥러닝 텐서(Tensor) 변환 전 단계의 배열 조작</font>
- **활용 시점:** Pandas로 정제된 데이터를 PyTorch나 Hugging Face Trainer에 입력하기 직전, 다차원 숫자 배열(Array) 형태로 변환하고 차원을 맞출 때 사용합니다.

- **예시:** 패딩(Padding) 처리를 위해 여러 길이의 토큰 ID 배열을 일정한 크기의 2차원 NumPy 배열(`np.zeros()`, `np.pad()`)로 정렬합니다.
 
<font color="#ff0000">3. 무작위 샘플링 및 데이터 셔플링 (Random Sampling & Shuffling)</font>
- **활용 시점:** 학습 데이터셋을 무작위로 섞거나(Shuffle), 학습용과 검증용(Train/Val)으로 인덱스를 쪼갤 때 난수를 고성능으로 생성하기 위해 사용합니다.
 
- **예시:** `np.random.permutation()`을 이용해 데이터셋 인덱스를 편향 없이 빠르게 섞어 모델 학습의 오버피팅을 방지합니다.

<font color="#ff0000">4. 판다스(Pandas) 성능 최적화가 필요한 연산</font>
- **활용 시점:** Pandas 데이터프레임 내부의 특정 컬럼에 복잡한 수치 계산이나 다차원 행렬 연산을 적용해야 할 때, 내부 데이터를 NumPy 배열로 추출(`df.to_numpy()`)하여 처리 속도를 극대화합니다.
