
### 1. Docker Desktop에 내장된 Kubernetes 설치

#### (1) Docker Desktop에 내장된 Kubernetes 설치
`Settings > Kubernetes > Enable Kubernetes > kubeadm은 단일 노드 클러스터`를 체크하고 `Apply & Restart`

#### (2) Docker Desktop에 내장된 `kubectl`을 `/usr/local/bin`으로 심볼릭 링크 연결

```bash
sudo ln -s /Applications/Docker.app/Contents/Resources/bin/kubectl /usr/local/bin/kubectl
```

- 설치가 완료되면 아래 명령어로 버전이 정상 출력되는지 확인
```bash
kubectl version
Client Version: v1.32.2
Kustomize Version: v5.5.0
Server Version: v1.32.2
```

- Docker Desktop의 쿠버네티스 컨텍스트와 잘 연동되어 있는지 확인
```bash
kubectl get nodes
```

### 2. minikube로 환경 구축

#### (1) homebrew 설치

```bash
brew install minikube
minikube version
```
kubernetes-cli 설치 여부 y시 kubectl 바로 사용 가능

#### (2) 클러스터 시작
```bash
minikube start --driver=docker --cpus=4 --memory=8192
```
