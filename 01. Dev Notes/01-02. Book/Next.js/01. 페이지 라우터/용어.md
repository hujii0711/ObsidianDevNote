
▪︎ FCP(First Contentful Paint)
사용자에게 처음 페이지의 콘텐츠를 렌더링하는 시점을 말한다.

▪︎ 라우팅
브라우저가 요청하는 URL 경로에 따라 적절한 페이지를 화면에 렌더링하기까지의 과정을 말한다.

▪︎ 마운트
리액트 컴포넌트가 처음으로 화면에 렌더링되는 시점을 의미한다.
즉, 컴포넌트가 메모리에 올라가고 HTML 요소로 변환되어 실제 DOM에 추가되는 순간을 '마운트된다'라고 표현한다.

▪︎ 핫 리로딩
개발 중에 코드를 수정하면 웹페이지를 새로고침하지 않아도 변경 사항을 자동으로 화면에 반영하는 기능이다.

▪︎ 트리셰이킹
작성한 코드 중 실제로 사용되지 않는 부분을 자동으로 제거하는 최적화 기법이다.
Next.js 같은 프레임워크에서는 빌드 과정에서 트리셰이킹을 자동으로 적용해 성능을 최적화한다.
