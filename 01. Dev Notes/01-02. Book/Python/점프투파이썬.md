7. 함수
- `*args`입력 값이 몇 개일지 모를때(160)
```python
def add_many(*args): # 매개변수 이름 앞에 *을 붙이면 입력값을 전부 모아 튜플로 만들어준다.
	result = 0
	for i in args:
		result = result + i
	return result
	
print(add_many(1, 2, 3, 4, 5))
```
