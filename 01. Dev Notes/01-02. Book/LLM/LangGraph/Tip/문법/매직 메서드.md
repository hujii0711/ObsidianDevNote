
# 파이썬 매직 메서드 정리

## 1. 정의

**매직 메서드**는 이름 앞뒤에 밑줄이 두 개씩 붙은 메서드(`__xxx__`)입니다. "dunder(double underscore) 메서드" 또는 공식 용어로 **특수 메서드(special method)**라고 부릅니다. 파이썬 공식 문서의 "데이터 모델(Data Model)" 장에 정의되어 있습니다.

핵심은 **직접 부르지 않는다**는 점입니다. 파이썬 문법이나 내장 함수를 쓰면 인터프리터가 대신 호출합니다.

```python
len(obj)        # → type(obj).__len__(obj)
a + b           # → type(a).__add__(a, b)
obj[k]          # → type(obj).__getitem__(obj, k)
with obj: ...   # → __enter__ / __exit__
```

그래서 내가 만든 클래스도 이 메서드를 정의하면 내장 타입(list, dict, int)과 같은 문법으로 쓸 수 있습니다.

### 공통 규칙 네 가지

1. **클래스(타입)에서만 찾는다.** 인스턴스에 메서드를 붙여도 문법에는 적용되지 않습니다.
   ```python
   class A: pass
   a = A()
   a.__len__ = lambda: 3
   len(a)   # TypeError: 인스턴스에 붙인 __len__은 무시됨
   ```
2. **처리할 수 없는 타입이 오면 `NotImplemented`를 반환한다.** 예외를 던지지 않고 이 값을 돌려주면 파이썬이 상대 객체의 반대쪽 메서드(`__radd__` 등)를 시도합니다. `NotImplementedError`와는 다른 것입니다.
3. **반환 타입이 정해져 있다.** `__len__`은 0 이상의 `int`, `__bool__`은 `bool`, `__repr__`·`__str__`은 `str`, `__hash__`는 `int`를 돌려줘야 하고 어기면 `TypeError`가 납니다.
4. **이름을 새로 만들지 않는다.** `__myfunc__`처럼 dunder 이름을 지어내지 마세요. 이 형식의 이름은 파이썬이 예약해 두었습니다.

## 2. 생성·초기화·소멸

| 메서드 | 호출 시점 | 비고 |
|---|---|---|
| `__new__(cls, ...)` | 인스턴스를 **만들 때** | 정적 메서드처럼 동작하며 새 인스턴스를 반환 |
| `__init__(self, ...)` | 만든 인스턴스를 **초기화할 때** | 반환값은 반드시 `None` |
| `__del__(self)` | 참조 횟수가 0이 되어 회수될 때 | 호출 시점이 보장되지 않음 |

```python
class Celsius(float):
    # 불변 타입(float, str, tuple)은 값이 __new__에서 정해지므로 __init__으로는 바꿀 수 없다
    def __new__(cls, value):
        if value < -273.15:
            raise ValueError("절대영도보다 낮을 수 없습니다")
        return super().__new__(cls, value)

class Singleton:
    _instance = None
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

- `__new__`가 `cls`의 인스턴스를 반환할 때만 `__init__`이 이어서 호출됩니다.
- `__del__`로 자원을 정리하지 마세요. 정리는 `with` 문(5장)이나 `weakref.finalize`로 하는 것이 안전합니다.

## 3. 문자열 표현

| 메서드 | 호출하는 쪽 | 용도 |
|---|---|---|
| `__repr__` | `repr()`, REPL 출력, 컨테이너 안에서 출력될 때 | 개발자용. 가능하면 객체를 다시 만들 수 있는 코드 형태로 |
| `__str__` | `str()`, `print()`, f-string | 사용자용. 읽기 쉬운 형태로 |
| `__format__(self, spec)` | `format()`, `f"{x:spec}"` | 서식 지정자 처리 |
| `__bytes__` | `bytes(obj)` | 바이트로 변환 |

```python
class Money:
    def __init__(self, amount): self.amount = amount
    def __repr__(self): return f"Money({self.amount!r})"
    def __str__(self):  return f"{self.amount:,}원"
    def __format__(self, spec):
        if spec == "만":
            return f"{self.amount / 10000:g}만원"
        return format(self.amount, spec)

m = Money(1500000)
print(m)          # 1,500,000원
[m]               # [Money(1500000)]  ← 리스트 안에서는 __repr__
f"{m:만}"         # 150만원
f"{m:>12,}"       # '   1,500,000'
```

`__str__`이 없으면 `__repr__`이 대신 쓰입니다. 하나만 만든다면 `__repr__`를 만드세요.

## 4. 비교·해시·참거짓

| 메서드 | 연산 |
|---|---|
| `__eq__`, `__ne__` | `==`, `!=` |
| `__lt__`, `__le__`, `__gt__`, `__ge__` | `<`, `<=`, `>`, `>=` |
| `__hash__` | `hash()`, dict 키, set 원소 |
| `__bool__` | `if obj:`, `bool()`, `and`/`or`/`not` |

```python
from functools import total_ordering

@total_ordering                      # __eq__와 __lt__만 있으면 나머지 비교 연산자를 만들어 줌
class Version:
    def __init__(self, major, minor):
        self.major, self.minor = major, minor
    def _key(self): return (self.major, self.minor)
    def __eq__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self._key() == other._key()
    def __lt__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self._key() < other._key()
    def __hash__(self):
        return hash(self._key())

sorted([Version(1, 2), Version(1, 0)])   # sorted()는 __lt__를 씀
{Version(1, 0), Version(1, 0)}           # 원소 하나: 같으면 해시도 같음
```

주의할 점:
- **`__eq__`를 정의하면 `__hash__`가 자동으로 `None`이 되어** 해시할 수 없는 객체가 됩니다. dict 키로 쓰려면 `__hash__`도 정의하세요.
- 같은 객체(`a == b`)는 반드시 해시도 같아야 합니다. 값이 바뀌는(가변) 객체는 해시를 제공하지 않는 것이 원칙입니다.
- `__ne__`는 기본으로 `__eq__`의 결과를 뒤집어 쓰므로 따로 정의할 필요가 거의 없습니다.
- `a < b`에서 `a.__lt__`가 `NotImplemented`를 반환하면 `b.__gt__(a)`를 시도합니다.
- `__bool__`이 없으면 `__len__() != 0`으로 판단하고, 둘 다 없으면 항상 `True`입니다.

## 5. 산술 연산자

### 이항 연산 (`a + b`)

| 연산 | 정방향 | 반사(오른쪽) | 제자리 |
|---|---|---|---|
| `+` | `__add__` | `__radd__` | `__iadd__` (`+=`) |
| `-` | `__sub__` | `__rsub__` | `__isub__` |
| `*` | `__mul__` | `__rmul__` | `__imul__` |
| `/` | `__truediv__` | `__rtruediv__` | `__itruediv__` |
| `//` | `__floordiv__` | `__rfloordiv__` | `__ifloordiv__` |
| `%` | `__mod__` | `__rmod__` | `__imod__` |
| `**` | `__pow__` | `__rpow__` | `__ipow__` |
| `@` | `__matmul__` | `__rmatmul__` | `__imatmul__` |
| `&` `\|` `^` | `__and__` `__or__` `__xor__` | `__rand__` … | `__iand__` … |
| `<<` `>>` | `__lshift__` `__rshift__` | `__rlshift__` … | `__ilshift__` … |
| `divmod()` | `__divmod__` | `__rdivmod__` | 없음 |

### 단항 연산과 변환

| 메서드 | 호출하는 쪽 |
|---|---|
| `__neg__`, `__pos__`, `__invert__` | `-a`, `+a`, `~a` |
| `__abs__` | `abs(a)` |
| `__int__`, `__float__`, `__complex__` | `int()`, `float()`, `complex()` |
| `__index__` | 슬라이싱 `seq[a]`, `bin()`, `hex()`, `range()` (정수로 손실 없이 바뀔 때만 정의) |
| `__round__`, `__trunc__`, `__floor__`, `__ceil__` | `round()`, `math.trunc/floor/ceil` |

```python
class Vec:
    def __init__(self, x, y): self.x, self.y = x, y
    def __repr__(self): return f"Vec({self.x}, {self.y})"

    def __add__(self, other):
        if not isinstance(other, Vec):
            return NotImplemented
        return Vec(self.x + other.x, self.y + other.y)

    def __mul__(self, k):
        if not isinstance(k, (int, float)):
            return NotImplemented
        return Vec(self.x * k, self.y * k)
    __rmul__ = __mul__              # 3 * v → int.__mul__ 실패 → v.__rmul__(3)

    def __neg__(self): return Vec(-self.x, -self.y)
    def __abs__(self): return (self.x ** 2 + self.y ** 2) ** 0.5

v = Vec(3, 4)
v + Vec(1, 1)   # Vec(4, 5)
3 * v           # Vec(9, 12)
abs(v)          # 5.0
```

- **반사 메서드 호출 순서**: `a + b`를 계산할 때 먼저 `a.__add__(b)`를 시도하고, `NotImplemented`면 `b.__radd__(a)`를 시도합니다. 둘 다 실패하면 `TypeError`가 납니다.
- **제자리 연산**: `__iadd__`가 없으면 `a += b`는 `a = a + b`로 처리되어 새 객체가 생깁니다. 가변 객체라면 `__iadd__`에서 자기 값을 고친 뒤 `self`를 반환합니다(list의 `+=`가 이렇게 동작함).
- `sum(vecs)`는 `0 + vecs[0]`부터 시작하므로 `__radd__`에서 `0`을 받아 처리하거나, `sum(vecs, Vec(0, 0))`처럼 시작값을 넘겨야 합니다.

## 6. 컨테이너·시퀀스·이터레이션

| 메서드 | 호출하는 쪽 |
|---|---|
| `__len__` | `len()` |
| `__getitem__(self, key)` | `obj[key]`, 슬라이싱(`key`가 `slice` 객체로 들어옴) |
| `__setitem__(self, key, value)` | `obj[key] = value` |
| `__delitem__(self, key)` | `del obj[key]` |
| `__contains__(self, item)` | `item in obj` |
| `__iter__` | `for`, `iter()`, 언패킹, `list()` |
| `__next__` | `next()`. 끝나면 `StopIteration`을 던짐 |
| `__reversed__` | `reversed()` |
| `__missing__(self, key)` | **dict 하위 클래스**에서 키가 없을 때 (`defaultdict`가 이렇게 동작함) |
| `__length_hint__` | `operator.length_hint()`. 길이를 추정해 미리 메모리를 잡을 때 |

```python
class Deck:
    def __init__(self, cards): self._cards = list(cards)
    def __len__(self): return len(self._cards)
    def __getitem__(self, i):
        if isinstance(i, slice):
            return Deck(self._cards[i])      # 슬라이스면 같은 타입으로 반환
        return self._cards[i]
    def __iter__(self):
        yield from self._cards               # 제너레이터로 만드는 것이 가장 간단

class Countdown:
    """이터레이터: __iter__가 self를 반환하고 __next__로 값을 하나씩 낸다"""
    def __init__(self, n): self.n = n
    def __iter__(self): return self
    def __next__(self):
        if self.n <= 0:
            raise StopIteration
        self.n -= 1
        return self.n + 1

class Config(dict):
    def __missing__(self, key):
        return f"<{key} 없음>"

list(Countdown(3))      # [3, 2, 1]
Config(a=1)["b"]        # '<b 없음>'
```

- `__getitem__`만 있어도 `for` 문과 `in`이 동작합니다(0부터 `IndexError`가 날 때까지 인덱스를 늘려 가는 옛 방식). 하지만 `__iter__`를 명시하는 것이 정석입니다.
- `__contains__`가 없으면 `in`은 순회하면서 하나씩 비교합니다.
- **이터러블과 이터레이터의 차이**: 이터러블은 `__iter__`가 호출될 때마다 새 이터레이터를 만들어 여러 번 순회할 수 있습니다. 이터레이터는 한 번 다 돌면 소진됩니다(위 `Countdown`).
- 직접 다 만들기보다 `collections.abc.Sequence`나 `MutableMapping`을 상속하면 필수 메서드 몇 개만으로 나머지 메서드가 채워집니다.

## 7. 호출: `__call__`

인스턴스를 함수처럼 `obj(...)`로 호출할 수 있게 합니다. **상태를 가진 함수**가 필요할 때 씁니다.

```python
class RateLimiter:
    def __init__(self, limit): self.limit, self.count = limit, 0
    def __call__(self, func):                   # 데코레이터로 사용
        def wrapper(*args, **kwargs):
            if self.count >= self.limit:
                raise RuntimeError("호출 한도 초과")
            self.count += 1
            return func(*args, **kwargs)
        return wrapper

@RateLimiter(limit=3)
def fetch(): ...
```

`callable(obj)`는 `__call__`이 있는지로 판단합니다. PyTorch의 `nn.Module`과 LangChain의 Runnable처럼 객체를 호출 가능하게 만드는 라이브러리가 많습니다.

## 8. 속성 접근

| 메서드 | 호출 시점 |
|---|---|
| `__getattr__(self, name)` | 일반 조회로 속성을 **못 찾았을 때만** |
| `__getattribute__(self, name)` | **모든** 속성 조회마다 (메서드 조회 포함) |
| `__setattr__(self, name, value)` | `obj.x = v` |
| `__delattr__(self, name)` | `del obj.x` |
| `__dir__` | `dir(obj)`, 자동완성 |

```python
class Proxy:
    """감싼 객체에 속성 접근을 위임하면서 기록을 남긴다"""
    def __init__(self, target):
        object.__setattr__(self, "_target", target)   # 아래 __setattr__을 거치지 않게
    def __getattr__(self, name):
        print(f"[get] {name}")
        return getattr(self._target, name)
    def __setattr__(self, name, value):
        print(f"[set] {name}={value!r}")
        setattr(self._target, name, value)

class Frozen:
    def __setattr__(self, name, value):
        if hasattr(self, name):
            raise AttributeError(f"{name}은 바꿀 수 없습니다")
        super().__setattr__(name, value)              # 실제 저장은 부모에게 맡김
```

- `__setattr__`와 `__getattribute__` 안에서 `self.x = ...`나 `self.x`를 쓰면 **자기 자신을 다시 호출해 무한 재귀**에 빠집니다. 반드시 `super().__setattr__`나 `object.__getattribute__(self, name)`를 쓰세요.
- `__getattr__`에서 처리할 수 없는 이름은 `AttributeError`를 던져야 합니다. 그래야 `hasattr`와 `getattr(obj, name, 기본값)`이 정상 동작합니다.
- 속성 하나를 검증하거나 계산하는 정도라면 `@property`가 더 간단합니다.

## 9. 디스크립터

| 메서드 | 호출 시점 |
|---|---|
| `__get__(self, obj, objtype=None)` | `instance.attr`, `Class.attr` 조회 |
| `__set__(self, obj, value)` | `instance.attr = value` |
| `__delete__(self, obj)` | `del instance.attr` |
| `__set_name__(self, owner, name)` | 클래스가 만들어질 때 자신이 붙은 속성 이름을 알려 줌 |

디스크립터는 **다른 클래스의 클래스 속성으로 놓여서** 그 속성에 대한 접근을 가로채는 객체입니다. 여러 속성에 같은 검증 로직을 붙일 때 씁니다.

```python
class Positive:
    def __set_name__(self, owner, name):
        self.private = "_" + name
    def __get__(self, obj, objtype=None):
        if obj is None:                  # Product.price처럼 클래스에서 조회한 경우
            return self
        return getattr(obj, self.private)
    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError(f"{self.private[1:]}는 양수여야 합니다")
        setattr(obj, self.private, value)

class Product:
    price = Positive()
    stock = Positive()
    def __init__(self, price, stock):
        self.price, self.stock = price, stock   # __set__을 거쳐 검증됨
```

- `__set__`이나 `__delete__`가 있으면 **데이터 디스크립터**로, 인스턴스의 `__dict__`보다 먼저 쓰입니다. `__get__`만 있으면 **비데이터 디스크립터**로, 인스턴스 `__dict__`에 같은 이름이 있으면 그쪽이 이깁니다.
- `property`, `classmethod`, `staticmethod`, 일반 함수(메서드 바인딩), `functools.cached_property`, ORM 필드가 모두 디스크립터로 만들어져 있습니다.

## 10. 컨텍스트 매니저 (`with` 문)

| 메서드 | 호출 시점 |
|---|---|
| `__enter__(self)` | `with` 블록에 들어갈 때. 반환값이 `as` 변수에 들어감 |
| `__exit__(self, exc_type, exc, tb)` | 블록을 나올 때. 예외가 나도 반드시 호출됨 |

```python
import time

class Timer:
    def __enter__(self):
        self.start = time.perf_counter()
        return self
    def __exit__(self, exc_type, exc, tb):
        self.elapsed = time.perf_counter() - self.start
        print(f"{self.elapsed:.3f}초")
        return False        # True를 반환하면 예외를 삼킴 (보통은 False/None)

with Timer() as t:
    sum(range(10**6))
```

- 예외 없이 끝나면 `__exit__`의 세 인자는 모두 `None`입니다.
- 간단한 경우에는 `contextlib.contextmanager` 데코레이터와 제너레이터(`yield` 앞뒤에 진입·정리 코드)로 같은 일을 할 수 있습니다.

## 11. 비동기 프로토콜

| 메서드 | 호출하는 쪽 | 비고 |
|---|---|---|
| `__await__` | `await obj` | **이터레이터**를 반환해야 함 |
| `__aiter__` | `async for` | 비동기 이터레이터를 반환 (`async def` 아님) |
| `__anext__` | `async for`의 각 단계 | `async def`. 끝나면 `StopAsyncIteration` |
| `__aenter__`, `__aexit__` | `async with` | 둘 다 `async def` |

```python
import asyncio

class Ticker:
    def __init__(self, n): self.n = n
    def __aiter__(self): return self
    async def __anext__(self):
        if self.n <= 0:
            raise StopAsyncIteration
        await asyncio.sleep(0.1)
        self.n -= 1
        return self.n

class DBSession:
    async def __aenter__(self):
        await asyncio.sleep(0)       # 연결 열기
        return self
    async def __aexit__(self, *exc):
        await asyncio.sleep(0)       # 연결 닫기

async def main():
    async with DBSession() as db:
        async for i in Ticker(3):
            print(i)
```

`async for`는 비동기 제너레이터(`async def` 안에서 `yield`)로 만드는 것이 가장 간단합니다.

## 12. 클래스 생성과 타입 검사

| 메서드 | 정의하는 곳 | 용도 |
|---|---|---|
| `__init_subclass__(cls, **kw)` | 부모 클래스 | 하위 클래스가 정의될 때 호출. 자동 등록·검증 |
| `__class_getitem__(cls, item)` | 클래스 | `MyClass[int]` 같은 제네릭 문법 |
| `__instancecheck__`, `__subclasscheck__` | **메타클래스** | `isinstance()`, `issubclass()` 결과를 바꿈 |
| `__subclasshook__` | ABC 클래스 | 상속 없이 메서드만 있어도 하위 클래스로 인정 |
| `__prepare__` | 메타클래스 | 클래스 본문을 실행할 네임스페이스를 준비 |
| `__mro_entries__` | 객체 | 클래스가 아닌 객체가 상속 목록에 올 때 대신 쓸 베이스를 지정 |

```python
class Plugin:
    registry = {}
    def __init_subclass__(cls, name=None, **kwargs):
        super().__init_subclass__(**kwargs)
        Plugin.registry[name or cls.__name__] = cls

class Csv(Plugin, name="csv"): ...
class Json(Plugin, name="json"): ...

Plugin.registry   # {'csv': <class Csv>, 'json': <class Json>}
```

메타클래스로 하던 일 대부분은 `__init_subclass__`나 클래스 데코레이터로 더 간단하게 할 수 있습니다.

## 13. 복사와 직렬화

| 메서드 | 호출하는 쪽 |
|---|---|
| `__copy__(self)` | `copy.copy()` |
| `__deepcopy__(self, memo)` | `copy.deepcopy()`. `memo`는 순환 참조를 막는 dict |
| `__getstate__`, `__setstate__(state)` | `pickle`과 `copy`가 상태를 저장·복원할 때 |
| `__reduce__`, `__reduce_ex__` | `pickle`. 객체를 다시 만드는 방법을 직접 지정 |
| `__getnewargs_ex__` | `pickle`이 `__new__`에 넘길 인자 |

```python
import threading

class Cache:
    def __init__(self):
        self.data = {}
        self.lock = threading.Lock()        # Lock은 피클할 수 없음
    def __getstate__(self):
        state = self.__dict__.copy()
        del state["lock"]                   # 직렬화에서 제외
        return state
    def __setstate__(self, state):
        self.__dict__.update(state)
        self.lock = threading.Lock()        # 복원할 때 새로 만듦
```

신뢰할 수 없는 데이터는 `pickle.loads`로 읽지 마세요. `__reduce__`를 통해 임의 코드가 실행될 수 있습니다.

## 14. 그 밖에 알아 둘 것

| 이름 | 종류 | 용도 |
|---|---|---|
| `__fspath__` | 메서드 | `os.PathLike` 프로토콜. `open()`과 `os.path`가 경로 문자열로 씀 |
| `__sizeof__` | 메서드 | `sys.getsizeof()` |
| `__buffer__`, `__release_buffer__` | 메서드 (3.12+) | 버퍼 프로토콜. `memoryview(obj)` |
| `__slots__` | 클래스 속성 | 허용할 인스턴스 속성을 고정. 인스턴스마다 `__dict__`가 없어져 메모리 절약 |
| `__match_args__` | 클래스 속성 | `match` 문의 위치 패턴 `case Point(x, y):`에서 쓸 속성 순서 |
| `__dict__`, `__class__`, `__module__`, `__doc__`, `__name__`, `__qualname__` | 속성 | 메서드가 아닌 특수 속성. 객체 정보를 확인할 때 |

## 15. 실무 팁

- **`@dataclass`부터 고려하세요.** `__init__`, `__repr__`, `__eq__`를 자동으로 만들어 줍니다. `order=True`를 주면 비교 연산자가, `frozen=True`를 주면 불변 객체와 `__hash__`가, `slots=True`를 주면 `__slots__`가 생깁니다.
- **추상 베이스 클래스(`collections.abc`)를 활용하세요.** `Mapping`, `Sequence`, `Iterable` 등을 상속하면 필수 메서드만 구현해도 나머지가 채워지고 `isinstance` 검사도 통과합니다.
- **연산자를 오버로딩할 때는 의미를 지키세요.** `+`가 덧셈이나 이어 붙이기가 아닌 일을 하면 코드를 읽는 사람이 헷갈립니다.
- **자주 나는 실수**
  - `__eq__`만 정의해서 해시할 수 없게 됨
  - `__setattr__` 안에서 `self.x = ...`를 써서 무한 재귀
  - 처리할 수 없는 타입에 `NotImplemented` 대신 `False`를 반환하거나 예외를 던져 반사 연산 기회를 막음
  - `__iter__`가 `self`를 반환해서 두 번째 순회부터 빈 결과가 나옴

이 문서를 [docs/Tip/](docs/Tip/)에 마크다운 파일로 저장할까요?
