
LangGraph 스트리밍 모드는 그래프의 실행 결과를 한 번에 기다리는 대신, 상태 변화와 노드별 업데이트, LLM 토큰 출력을 실시간으로 확인하게 해준다.
그래프 실행 중에 발생하는 상태 변화와 LLM 출력을 실시간으로 확인할 수 있는 다양한 스트리밍 모드를 제공한다. 그래프의 각 노드가 실행될 때마다 중간 결과를 즉시 전달받을 수 있으며, 토큰 단위의 응답 스트리밍까지 구현할 수 있다.

## 1. 노드 단계별로 출력하기
LangGraph의 스트리밍은 단순히 LLM 출력시 토큰 단위로 스트리밍하는 개념이 아니라, 그래프의 각 <mark style="background:#fff88f">노드가 실행될 때마다 단계별로 결과를 출력</mark>하는 것을 의미한다.
따라서 각 노드의 실행 완료 시점마다 중간 결과를 실시간으로 받아볼 수 있다.(그래프 실행의 중간 과정을 실시간으로 확인 가능)

- values: 각 노드가 호출된 후의 그래프 전체 상태, 즉 각 단계의 현재 상태 값을 스트리밍한다.
	chunk.items() # chunk는 dict 형태
		- key: state의 key 값
		- value: state의 key에 해당하는 value

- updates: 각 노드가 호출된 후 해당 노드에서 상태에 대한 변경된 내용만 스트리밍한다.(기본값)
	chunk.items() # chunk는 dict 형태
		- key: 노드 이름
		- value: 변경된 값으로 dict 형태(key, value)로 반환. 노드의 변경된 상태를 확인 가능.

- messages: 각 노드의 메시지를 스트리밍한다. 이 때 LLM의 토큰 단위 출력 스트리밍도 가능하다.
	사용자에게 응답이 생성되는 과정을 실시간으로 보여줄 수 있다.
	chunk_msg, metadata = chunk
		- chunk_msg: 실시간 출력 메시지
		- meta_data: 노드 정보(어떤 노드에서 발생한 메시지인지 확인 가능)
