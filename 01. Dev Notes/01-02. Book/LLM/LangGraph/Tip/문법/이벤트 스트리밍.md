
## 이벤트 스트리밍 v3: `stream_events(version="v3")`
LangGraph 1.2 / LangChain 1.3 부터는 새로운 **이벤트 스트리밍 v3** 가 추가되었습니다. 기존 `astream_events(version="v2")` 가 `on_chat_model_stream` 같은 원시 이벤트 딕셔너리를 그대로 돌려주는 반면, v3 는 **실행 스트림 객체**를 반환하고 그 위에 타입이 지정된 프로젝션(`messages`, `subgraphs`, `output` 등)을 제공합니다. 네임스페이스 문자열을 직접 파싱하거나 이벤트 종류를 일일이 분기할 필요 없이, 필요한 관점만 골라서 소비할 수 있습니다.

| 프로젝션 | 설명 |
|----------|------|
| `stream.messages` | 채팅 모델 출력 메시지. `message.text` 로 토큰 단위 순회, `message.tool_calls` 로 도구 호출 청크 접근 |
| `stream.subgraphs` | 서브그래프 실행. `subgraph.graph_name`, `subgraph.path`, 그리고 서브그래프 내부의 `messages` |
| `stream.output` | 최종 상태 (동기: 속성, 비동기: `await stream.output()`) |


> 참고: v3 이벤트 스트리밍은 현재 **beta** 이며 API 가 변경될 수 있습니다. 공식 문서: [Event streaming](https://docs.langchain.com/oss/python/langgraph/event-streaming)

아래 코드는 v3 스트림의 `messages` 프로젝션으로 LLM 토큰을 순회하고, 마지막에 최종 상태를 확인합니다. (비동기 환경에서는 `await graph.astream_events(..., version="v3")` 로 스트림 객체를 얻고 `async for` 로 순회합니다.)

## 정리

이번 튜토리얼에서는 LangGraph의 다양한 스트리밍 모드를 살펴보았습니다.

**핵심 내용:**
- `stream_mode="values"` 를 사용하면 각 단계의 전체 상태를 확인할 수 있습니다.
- `stream_mode="updates"` 를 사용하면 각 노드에서 변경된 업데이트만 효율적으로 확인할 수 있습니다.
- `stream_mode="messages"` 를 사용하면 LLM 의 토큰 단위 실시간 스트리밍이 가능합니다.
- `astream_events(version="v2")` 를 사용하면 이벤트 단위로 세밀한 제어가 가능하며, 태그 기반 필터링도 지원합니다.
- `astream_events(version="v3")` 는 실행 스트림 객체를 반환하며, `messages` / `subgraphs` / `output` 프로젝션으로 원하는 관점만 간결하게 소비할 수 있습니다 (beta).
- 서브그래프 스트리밍 시 `subgraphs=True` 옵션으로 내부 업데이트를 포함하거나 생략할 수 있습니다.

이러한 스트리밍 모드를 적절히 활용하면, 사용자 경험을 향상시키는 실시간 응답 시스템을 구축할 수 있습니다.
