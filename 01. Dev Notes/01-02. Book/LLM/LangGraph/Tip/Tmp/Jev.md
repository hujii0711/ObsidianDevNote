
**Jev**는 2026년 9월 샌프란시스코의 AI 연구기업 **TypeSafe AI**가 공개한 비생성형 의사결정 전용 AI 모델(System One Model)입니다.

기존 LLM(대규모 언어 모델)이 자연어 텍스트를 생성(Generation)하는 데 초점을 맞추는 반면, Jev는 **텍스트를 한 글자도 생성하지 않고 애플리케이션의 상태(State)와 타입이 지정된 질문(Typed Questions)을 입력받아 구조화된 판단 결과(Yes/No, 선택지, 점수 등)와 보정된 확률값(Calibrated Probabilities)을 밀리초(ms) 단위로 반환**하도록 설계되었습니다.

### 1. 핵심 개념: System 1 vs System 2 역할 분담
심리학자 대니얼 카너먼의 '빠른 직관(System 1)'과 '느린 숙고(System 2)' 개념을 AI 에이전트 아키텍처에 적용한 모델입니다.

- **기존 LLM (System 2 역할):** 복잡한 추론, 계획 수립, 코드/문서 작성 등 고차원적 생성 작업을 담당합니다. 하지만 단순 분기 판단이나 도구 선택에도 매번 토큰을 생성해야 하므로 지연 시간(Latency)과 비용이 크고, 파싱 오류(JSON 깨짐 등) 위험이 있습니다.

- **Jev (System 1 역할):** 에이전트 루프 내부에서 발생하는 수많은 **중간 판단, 라우팅, 필터링, 검증**을 단일 병렬 패스(Single parallel pass)로 처리합니다. TypeSafe AI 측은 기존 LLM 대비 수백 배 빠른 속도와 압도적으로 낮은 비용으로 동작한다고 설명합니다.

### 2. 동작 방식 (입력과 출력)
Jev는 자체 개발한 강화학습 기법(**RLCD**: Reinforcement Learning for Calibrated Decisions)으로 학습되었으며, 코드가 곧바로 제어 흐름(`if/else`, 라우팅)에 쓸 수 있는 타입 안전(Type-safe) 출력을 보장합니다.

1. **State (상태 제공):** 현재 에이전트의 대화 맥락, 사용자 입력, 검색된 문서 등 애플리케이션 상태 데이터를 전달합니다.
2. **Typed Questions (질문 정의):** 여러 개의 독립적인 질문을 동시에 정의합니다.
    - _Boolean:_ "사용자가 환불을 요청하고 있는가?" (`true / false`)
    - _Choice (선택형):_ "이 요청을 처리할 적절한 도구는 무엇인가?" (`["search_db", "call_api", "ask_user"]`)
    - _Score (점수/확률):_ "검색된 문서가 질문과 관련이 있는 정도는?" (`0.0 ~ 1.0`)
3. **Structured Answers (병렬 응답):** 정의된 모든 질문에 대한 답과 신뢰도(확률값)를 한 번의 추론으로 동시에 반환합니다. 신뢰도가 임계치(Threshold) 미만일 경우에만 무거운 LLM(System 2)으로 폴백(Fallback)하도록 설계할 수 있습니다.

### 3. AI 에이전트(LangGraph 등) 접목 포인트
LangChain 및 LangGraph 생태계에서도 공식 통합(`langchain-typesafe`)을 지원하며, 주로 **에이전트 하네스(Harness)의 제어 계층**에 배치됩니다.

- **조건부 엣지(Conditional Edge) 및 라우팅:** LangGraph의 `StateGraph`에서 다음 노드로 넘어가기 전, 무거운 LLM을 호출해 도구 선택이나 분기를 결정하는 대신 Jev가 밀리초 단위로 경로를 결정합니다.

- **RAG 검색 결과 필터링 및 리랭킹(Reranking):** 벡터 DB에서 가져온 청크(Chunk)들이 실제 질의에 유효한지 병렬로 빠르게 판별(Yes/No 및 점수화)하여 컨텍스트 윈도우 낭비와 환각을 줄입니다.

- **가드레일(Guardrails) 및 정책 검증:** 사용자 입력의 프롬프트 인젝션 여부나 에이전트 출력의 정책 위반 여부를 실시간으로 판별합니다.

- **에이전트 평가(Evals):** LangSmith 등의 평가 파이프라인에서 텍스트 기반 LLM-as-a-Judge 대신 보정된 확률 점수를 내놓는 평가기(Evaluator)로 활용됩니다.

### 요약

|**구분**|**기존 LLM (GPT, Claude, Qwen 등)**|**Jev (TypeSafe AI)**|
|---|---|---|
|**모델 성격**|생성형 모델 (System 2)|비생성형 결정 모델 (System 1)|
|**출력 형태**|자유 텍스트 (Structured Output 파싱 필요)|타입이 고정된 값 (`bool`, `enum`, `float` 확률)|
|**처리 방식**|순차적 토큰 생성 (Autoregressive)|다중 질문 단일 병렬 패스|
|**에이전트 내 역할**|추론, 계획 수립, 최종 답변/코드 생성|라우팅, 도구 선택, RAG 필터링, 가드레일, 평가|

정리하면, **Jev는 LLM을 대체하는 모델이 아니라, 에이전트 루프 속에서 '생각(생성)'과 '판단(분기)'을 분리해 에이전트의 속도와 안정성, 비용 효율을 극대화하는 의사결정 전용 레이어**입니다.
