##### 1. add_messages 리듀서
```python
messages: Annotated[list[AnyMessage], add_messages]
```
add_messages 리듀서는 상태 그래프(StateGraph)에서 메시지 리스트를 병합하는 데 사용됩니다. 이 리듀서를 사용하면, <mark style="background:#fff88f">각 노드에서 반환된 메시지들이 기존 메시지 리스트에 추가되어 최종적으로 모든 메시지를 누적</mark>할 수 있습니다.
아래 예제에서는 `MessagesState`라는 상태를 정의하고, `messages` 필드에 `add_messages` 리듀서를 지정합니다.
챗봇 노드에서는 마지막 메시지를 받아 응답을 생성하고, 이 응답 메시지를 기존 메시지 리스트에 추가합니다.

##### 2. MessagesState
LangGraph는 메시지 목록을 상태로 다루기 위해 사전 정의된 `MessagesState`를 제공합니다.
이 상태는 메시지 리스트를 관리하며, 각 노드에서 반환된 메시지를 기존 메시지 리스트에 추가하는 `add_messages` 리듀서를 사용합니다.

##### 3. 노드 함수 안에서 state와 config 접근
```python
# config 매개변수로 thread_id 전달
result = graph.invoke(
	{"input": "테스트"}, config={"configurable": {"thread_id": "thread-1"}}
)

def node_with_config(state: State, config: RunnableConfig):
	"""config를 사용하는 노드: thread_id 등 설정 정보 접근 가능"""
	# config에서 thread_id 추출 (없으면 "unknown")
	thread_id = config.get("configurable", {}).get("thread_id", "unknown")
	print(f"Thread ID: {thread_id}")
	# Thread ID: thread-1
	
def plain_node(state: State):
	"""기본 노드: state만 사용"""
	print(f"TEST: {state.get('input')}")
	# TEST: 테스트
	return {"results": f"처리됨: {state['input']}"}
```

##### 4. 조건부 엣지(add_conditional_edges)
조건부 엣지는 특정 노드에서 다음 노드로 이동할 때, 라우팅 조건에 따라 분기되는 엣지를 의미합니다

##### 5. 라우팅 함수
라우팅 함수는 상태(state)의 값을 확인하여, 실행될 노드를 분기하는 함수입니다.

```python
def routing_function(state: State):
	"""라우팅 함수: value가 짝수면 'even', 홀수면 'odd' 반환"""
	if state["value"] % 2 == 0:
		return "even"
	else:
		return "odd"
		
builder.add_conditional_edges(
	"node_a", routing_function, {"even": "node_b", "odd": "node_c"}
)
```
