# DLL 파일의 일반적 역할과 본 프로젝트에서의 쓰임새

## 1. DLL(Dynamic Link Library)의 일반적 역할

DLL은 **동적 연결 라이브러리**로, 실행 파일(.exe)이 실행 시점에 불러다 쓰는 **재사용 가능한 코드·데이터 묶음**입니다. 핵심 성격은 다음과 같습니다.

| 특성 | 설명 |
|------|------|
| **모듈화** | 기능 단위(통신/보안/화면/장치)로 코드를 분리해 개발·배포·교체를 독립적으로 수행 |
| **공유·재사용** | 여러 exe가 하나의 DLL을 동시에 참조 → 메모리·디스크 절약 |
| **동적 로딩** | 프로그램 실행 중 필요할 때 로드/언로드(`LoadLibrary`) → 플러그인·드라이버 구조에 적합 |
| **부분 업데이트** | 특정 기능만 담은 DLL 하나만 교체하면 전체 재빌드·재배포 없이 패치 가능 |
| **언어·기술 혼재** | 네이티브(C/C++), .NET(관리형), VB6 등 서로 다른 기술로 만든 모듈을 한 프로세스에서 결합 |

즉 DLL은 **"exe 본체가 실행 시 조립해 쓰는 부품"** 이며, 특히 이 프로젝트처럼 은행 창구단말은 통신·보안·주변장치가 수시로 바뀌므로 **DLL/OCX 단위 부분 배포·교체**가 핵심 운영 전략입니다.

## 2. 본 프로젝트에서의 DLL 쓰임새

### ① iWorks 프레임워크 코어 (`Izt*` 네이티브 엔진) ― 애플리케이션의 심장
| DLL                                            | 역할                                                                                                                   |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `IztScript.dll`                                | **스크립트 실행 엔진** ― `Code/*.dat` 업무 스크립트를 구동. ※ MFC/C++ 소스가 [IztScript/](IztScript/)에 존재 (2026-07-23 추가, 내장함수 290개 구현부) |
| `IztScreen.dll`                                | 화면(폼) 렌더링·표시                                                                                                         |
| `IztSession.dll`                               | 세션(로그인/상태) 관리                                                                                                        |
| `IztTran.dll`                                  | 전문(거래) 송수신 처리                                                                                                        |
| `IztControl.dll` / `IztMenu.dll`               | UI 컨트롤·메뉴                                                                                                            |
| `IztCommon.dll` / `IztUtil.dll`                | 공통 유틸리티                                                                                                              |

> `IztScript.dll`을 제외한 나머지 코어 DLL의 소스는 벤더(Inzent) 보유로 프로젝트에 없습니다.

## 3. 요약

이 프로젝트에서 DLL은 크게 **① iWorks 엔진 코어, ② 통신, ③ 보안, ④ 창구 주변장치 드라이버, ⑤ .NET 서비스, ⑥ 압축·이미지, ⑦ UI·런타임**의 7개 계층으로 나뉩니다. exe(에이전트/런처)와 `Code/*.dat` 업무 스크립트는 **껍데기·시나리오**이고, **실제 기능은 전부 이 DLL/OCX 부품들이 조립되어 수행**합니다. 그래서 은행 창구단말 특성상 장치·보안·통신 모듈을 **DLL 단위로 버전 관리하며 부분 배포·교체**하는 것이 이 시스템의 핵심 운영 방식입니다. 이 중 스크립트 엔진(`IztScript.dll`)은 [IztScript/](IztScript/) 소스가 확보되어 직접 분석·수정이 가능해졌습니다.
