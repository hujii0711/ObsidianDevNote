LLM 모델 이름에 **`Instruct`** (또는 `Chat`, `IT`)가 붙어 있는 것과 없는 것(주로 **`Base`** 모델이라고 부름)은 **모델이 학습된 방식과 목적**에서 아주 큰 차이가 있습니다. 

쉽게 설명해 드리겠습니다.

---

### 1. Base 모델 (Instruct가 없는 모델)
*   **특징:** 세상의 방대한 텍스트(인터넷 글, 책, 코드 등)를 읽고, **'다음 단어가 무엇일지 예측'**하는 기초적인 능력만 학습한 상태의 모델입니다.
*   **대화 방식 (예시):**
    *   **사용자 입력:** "대한민국의 수도는 어디인가요?"
    *   **Base 모델의 답변:** "일본의 수도는 어디인가요? 중국의 수도는 어디인가요?" (질문에 답하는 것이 아니라, 문맥상 이어질 법한 텍스트를 그냥 이어서 써버립니다.)
*   **용도:** 이 모델 자체로는 챗봇으로 쓰기 어렵습니다. 대신, 연구자들이나 개발자들이 자신만의 특수한 챗봇이나 특정 도메인 전용 모델을 **처음부터 밑바닥부터 가르치기 위한(파인튜닝하기 위한) '원석'**으로 사용합니다.

### 2. Instruct 모델 (Instruct가 있는 모델)
*   **특징:** Base 모델을 가져다가 **'사람의 지시(Instruction)를 따르고 대화하는 방법'을 추가로 가르친(파인튜닝한) 모델**입니다. 이 과정을 SFT(Supervised Fine-Tuning) 및 RLHF(인간 피드백 기반 강화학습)라고 부릅니다.
*   **대화 방식 (예시):**
    *   **사용자 입력:** "대한민국의 수도는 어디인가요?"
    *   **Instruct 모델의 답변:** "대한민국의 수도는 서울입니다." (질문의 의도를 파악하고 알맞은 대답을 합니다.)
*   **용도:** 우리가 흔히 아는 ChatGPT나 Claude처럼 즉시 질문하고 답변을 받을 수 있는 형태입니다. 바로 서비스에 가져다 쓰거나 챗봇으로 활용하기 좋습니다.

### 💡 파인튜닝을 할 때 어떤 것을 선택해야 할까요?

고객님의 목표인 **'한국어 업무 챗봇 만들기'**를 기준으로는 다음과 같이 접근하는 것이 좋습니다.

**결론: `Instruct` 모델을 베이스로 가져와서 파인튜닝하는 것을 강력히 추천합니다.**

**이유:**
1.  **대화 능력 확보:** 이미 '질문에 대답하는 법', '친절하게 말하는 법', '요약하는 법' 등 기본적인 챗봇의 소양을 다 갖추고 있습니다.
2.  **데이터 절약:** Base 모델에 대화하는 법부터 가르치려면 수만 건 이상의 고품질 대화 데이터(질문-답변 세트)가 필요합니다. 반면, Instruct 모델을 쓰면 "우리 회사 업무 규정은 이렇다", "사내 말투는 이렇게 해라" 같은 **회사 특화 지식(도메인 지식)이나 특유의 말투를 입히는 데 적은 데이터(수백~수천 건)로도 훌륭한 결과**를 낼 수 있습니다.

따라서 계획서에 적힌 대로 **`Qwen-14B-Instruct`**와 같이 뒤에 Instruct가 붙은 모델을 다운로드하여, 고객님의 회사 업무 데이터로 LoRA 파인튜닝을 진행하시는 방향이 가장 빠르고 효율적인 지름길입니다!

---
쉽게 말하면:

- **instruct 없는 모델 = base model**
- **instruct 있는 모델 = 사람 지시를 따르도록 추가 학습된 모델**

## Base 모델

예: `Qwen3-14B`, `Llama-3-8B`, `Mistral-7B`

Base 모델은 기본적으로 “다음 토큰 예측”에 최적화되어 있습니다. 문장을 이어 쓰는 능력은 좋지만, 사용자의 명령을 안정적으로 따르도록 훈련된 것은 아닙니다.

예를 들어:

```text
사용자: 다음 문장을 요약해줘: ...
```

base 모델은 요약을 하기보다 문장을 이어 쓰거나, 이상한 형식으로 답할 수 있습니다.

주로 쓰는 경우:

- 연구용
- 처음부터 직접 instruction tuning 하려는 경우
- 특정 도메인 모델을 강하게 커스터마이징하려는 경우
- continued pretraining, domain-adaptive pretraining

## Instruct 모델

예: `Qwen3-14B-Instruct`, `Llama-3-8B-Instruct`, `Mistral-7B-Instruct`

Instruct 모델은 base 모델에 추가로 **instruction tuning**, **chat tuning**, 경우에 따라 **RLHF/DPO** 같은 정렬 학습을 거친 모델입니다.

즉 이런 걸 더 잘합니다:

- “요약해줘”
- “표로 정리해줘”
- “한국어로 답해줘”
- “모르면 모른다고 해”
- “이 형식으로 JSON 출력해”
- “친절하지만 짧게 답해”

일반 챗봇, 업무 비서, RAG, 고객 응대, 문서 QA에는 보통 instruct 모델이 맞습니다.

## 파인튜닝할 때는 뭘 써야 하나?

사용 목적이 **한국어 업무 챗봇**이면 대부분은 **Instruct 모델에서 LoRA 파인튜닝**하는 게 좋습니다.

추천:

```text
Qwen3-8B-Instruct → 먼저 실험
Qwen3-14B-Instruct → 최종 후보
```

Base 모델을 쓰면 “말을 잘 듣는 챗봇”을 만들기 위한 학습량이 더 많이 필요합니다. 반면 Instruct 모델은 이미 대화/지시 수행 능력이 있어서, 내 데이터로 말투·업무 지식·응답 형식만 맞추면 됩니다.

정리하면:

| 구분 | Base | Instruct |
|---|---|---|
| 목적 | 텍스트 생성 기반 모델 | 지시 수행/대화용 |
| 챗봇 적합성 | 낮음 | 높음 |
| 파인튜닝 난이도 | 높음 | 낮음 |
| 데이터 요구량 | 많음 | 상대적으로 적음 |
| 업무 QA/RAG | 비추천 | 추천 |

현재 목적이라면 **instruct 붙은 모델을 고르세요.**
