## 실제 조합 — TranMCI의 경우

```cpp
int nScreenOption = SCREEN_COMPLETE | SCREEN_OUTPUT;    // 0x1010  (일반 출력)
    ...
    nScreenOption |= SCREEN_DATAAPPEND;                 // 0x5010  (대량 출력)
```

셋이 만드는 동작을 한 문장으로 풀면:

> **"출력 전용 화면(`OUTPUT`)을, 이 자리에서 다 끝날 때까지 기다리며(`COMPLETE`), 이미 열려 있으면 새로 열지 말고 그리드에 이어붙여라(`DATAAPPEND`)."**

세 플래그가 서로 간섭하지 않는 이유는 읽는 주체가 전부 다르기 때문입니다:

```
SCREEN_COMPLETE    → CPlatformImpl::LoadScreen()      (메시지 발송 직전)
SCREEN_DATAAPPEND  → CPowerWorksApp::OnLoadScreenRap() (화면 오픈 분기)
SCREEN_OUTPUT      → CKes::ScreenOpenComplete()        (화면 오픈 완료 후)
```
