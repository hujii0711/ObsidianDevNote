YouTube 쇼츠 한 편은 보통 아래 10단계를 거쳐 만들어집니다. 지금 쓰시는 로컬 Qwen 모델 하나로 어디까지 할 수 있는지도 함께 표시했습니다.

## 쇼츠 제작 단계

| # | 단계 | 하는 일 | 나오는 결과물 | 필요한 도구 | 로컬 LLM만으로 가능? |
|---|---|---|---|---|---|
| 1 | **주제 리서치** | 트렌드·키워드·경쟁 영상 조사, 사실 자료 수집 | 주제 후보 목록, 참고 자료 | Tavily(설치됨), YouTube Data API | ✅ (Tavily 포함) |
| 2 | **기획** | 타깃 시청자, 콘셉트, 첫 1~3초에 시선을 잡을 **훅** 결정 | 기획안 | LLM | ✅ |
| 3 | **대본 작성** | 훅 → 본문 → 마무리(구독 유도) 구조로 작성. 한국어 기준 60초에 약 300자 내외 | 나레이션 대본 | LLM | ✅ |
| 4 | **장면 분할(스토리보드)** | 대본을 장면 5~10개로 나누고, 장면마다 대사·화면 설명·길이 지정 | 장면 목록(JSON) | LLM + 구조화 출력 | ✅ |
| 5 | **화면 소스 확보** | 장면별 이미지나 영상 준비 | 이미지·영상 클립 | AI 이미지 생성(Stable Diffusion/FLUX, 유료 API), 스톡 영상(Pexels API) | ❌ 별도 도구 필요 |
| 6 | **음성·배경음** | 대본을 음성(TTS)으로 만들고 배경음악 선택 | 나레이션 mp3, BGM | edge-tts(무료), ElevenLabs·OpenAI TTS(유료) | ❌ 별도 도구 필요 |
| 7 | **자막** | 음성에 맞춰 자막 타이밍 생성. 쇼츠는 단어 단위 큰 자막이 일반적 | 자막 파일(srt/ass) | Whisper(타임스탬프 추출) | ❌ 별도 도구 필요 |
| 8 | **편집·렌더링** | 세로 **9:16, 1080×1920**으로 장면·음성·자막·BGM 합성. 확대·전환 효과 추가 | 최종 mp4 | ffmpeg, moviepy | ❌ 코드 실행 필요 |
| 9 | **제목·설명·태그 작성** | 제목, 설명, 해시태그(`#shorts` 등) 작성 | 업로드 정보 | LLM | ✅ |
| 10 | **검수 → 업로드** | 길이(최대 3분), 사실관계, 저작권(이미지·음악), 정책 확인 후 업로드·예약 | 게시된 영상 | YouTube Data API v3 (OAuth 필요) | ❌ API 연동 필요 |
| (+) | 성과 분석 | 조회수·시청 지속률을 보고 다음 주제·훅에 반영 | 개선 포인트 | YouTube Analytics API | 선택 사항 |

## 정리하면
- **1~4단계와 9단계(기획·글쓰기)**는 지금 환경(LangGraph + 로컬 Qwen + Tavily)으로 바로 만들 수 있습니다. 이 단계는 LLM 에이전트가 잘하는 영역입니다.
- **5~8단계(미디어 생성)**는 LLM이 직접 하지 않습니다. 에이전트가 TTS, 이미지 생성, ffmpeg 같은 **도구를 호출**하는 방식입니다. 무료 로컬 도구로 갈지 유료 API로 갈지에 따라 품질과 비용이 크게 달라집니다.
- **10단계(업로드)**는 실제 채널에 올라가므로, 자동으로 올릴지 사람이 최종 확인한 뒤 올릴지를 정해야 합니다. LangGraph의 `interrupt`로 사람 확인 단계를 넣을 수 있습니다.

이 중 **에이전트가 자동으로 처리했으면 하는 단계는 어디까지인가요?** 그리고 직접 손대고 싶은 단계가 있다면 알려주세요. 이 범위에 따라 에이전트를 몇 개로 나눌지가 정해집니다.

## 단계별 도구 추천 (무료 / 유료)

> 기준: Apple Silicon Mac + Python(LangChain/LangGraph) 환경에서 **코드로 호출할 수 있는 도구** 위주.
> 가격·무료 한도는 자주 바뀌므로 도입 전에 각 서비스 요금 페이지를 확인하세요.

### 1. 주제 리서치

| 구분 | 도구 | 특징 |
|---|---|---|
| 무료 | **Tavily** (설치됨) | 무료 플랜 월 1,000 크레딧. 웹 검색·요약에 충분 |
| 무료 | DuckDuckGo Search (`langchain-community`) | API 키 불필요. 품질은 Tavily보다 낮음 |
| 무료 | **YouTube Data API v3** | 인기 영상·검색 결과 조회. 하루 10,000 유닛 무료 |
| 무료 | pytrends (Google Trends) | 비공식 라이브러리라 자주 막힘. 보조용 |
| 유료 | Tavily 유료 플랜, Perplexity Sonar API, SerpAPI | 검색량이 많거나 출처 품질이 중요할 때 |

### 2~4, 9. 기획 · 대본 · 장면 분할 · 제목/태그 (LLM)

| 구분 | 도구 | 특징 |
|---|---|---|
| 무료 | **로컬 Qwen3.6-35B (mlx_lm, 현재 사용 중)** | 비용 0. 초안·장면 분할·JSON 구조화 출력에 충분 |
| 유료 | **Claude API** (Sonnet 5.5 / Haiku 5.5) | 한국어 훅·대본 품질이 좋음. `langchain-anthropic`으로 교체 |
| 유료 | OpenAI API | [config/model.py](../config/model.py)가 이미 `ChatOpenAI`라 `base_url`만 바꾸면 됨 |

> 팁: "초안은 로컬, 최종 대본·훅 다듬기만 유료 모델" 식으로 나누면 비용을 크게 줄일 수 있음.

### 5. 화면 소스 (이미지 · 영상)

| 구분 | 도구 | 특징 |
|---|---|---|
| 무료 | **Pexels API / Pixabay API** | 무료 스톡 사진·세로 영상. 상업적 사용 가능, API 키만 발급 |
| 무료 | **mflux** (FLUX on MLX) | Mac에서 로컬 이미지 생성. `FLUX.1-schnell`은 상업적 사용 가능(Apache 2.0), `dev`는 비상업 라이선스 |
| 무료 | ComfyUI / Draw Things | 로컬 Stable Diffusion·FLUX. ComfyUI는 API 서버로 호출 가능 |
| 유료 | OpenAI 이미지 API, Google Imagen(Gemini) | 프롬프트 이해도·텍스트 표현이 좋음 |
| 유료 | FLUX API (fal.ai, Replicate 경유) | 로컬보다 빠르고 고품질 모델(pro) 사용 가능 |
| 유료 | AI 영상 생성: Google Veo, Runway, Kling | 장면당 비용이 커서 핵심 장면에만 쓰는 것을 권장 |

### 6. 음성(TTS) · 배경음악

| 구분 | 도구 | 특징 |
|---|---|---|
| 무료 | **edge-tts** | 한국어 음성(SunHi, InJoon 등) 자연스러움. 단어별 타이밍 이벤트 제공 → 자막 생성에 활용. **비공식 사용이라 약관 회색지대이고 언제든 막힐 수 있음** |
| 무료 | MeloTTS | 로컬 실행, 한국어 지원. 품질은 edge-tts보다 낮음 |
| 무료(한도) | Google Cloud TTS | 월 무료 한도 있음. 한국어 음성 품질 양호, 공식 API |
| 유료 | **ElevenLabs** | 가장 자연스러운 편, 목소리 복제 가능. 글자 단위 타임스탬프 API 제공. 무료 플랜은 비상업용 |
| 유료 | OpenAI TTS, Naver CLOVA Voice, Typecast | CLOVA·Typecast는 한국어 억양이 강점 |
| 무료 BGM | YouTube 오디오 보관함, Pixabay Music | 저작권 안전. YouTube 오디오 보관함은 API가 없어 수동 다운로드 |
| 유료 BGM | Epidemic Sound, Artlist, Suno(AI 작곡) | Suno 무료 플랜은 상업적 사용 불가 |

### 7. 자막 (타이밍)

| 구분 | 도구 | 특징 |
|---|---|---|
| 무료 | **TTS 타임스탬프 재사용** | 대본을 이미 알고 있으므로 edge-tts·ElevenLabs의 타이밍 정보로 바로 srt 생성 가능 (가장 정확) |
| 무료 | **mlx-whisper** / faster-whisper | 로컬 음성 인식으로 단어별 타임스탬프 추출. mlx-whisper는 Apple Silicon 최적화 |
| 유료 | OpenAI 전사 API, Deepgram, AssemblyAI | 로컬 연산이 부담될 때 |

### 8. 편집 · 렌더링

| 구분 | 도구 | 특징 |
|---|---|---|
